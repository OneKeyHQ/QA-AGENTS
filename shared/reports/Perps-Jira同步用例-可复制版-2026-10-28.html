前置条件与测试数据

• 准备有链上余额和网络手续费的测试账户、可提现 USDC 账户、空账户、观察账户；软件钱包、私钥钱包、硬件钱包、二维码硬件及支持的外部钱包各备可签名账户。观察账户仅验证展示及禁止发起的边界。

• 在当前启用的存款列表中回归：Arbitrum 的 USDC / ETH / USDT / USDC.e，Ethereum 的 ETH / USDT / USDC，Solana 的 SOL / USDT / USDC，Base 的 ETH / USDT / USDC，Polygon 的 POL / USDT / USDC，OP 的 ETH / USDT0 / USDC。每个启用组合至少核对选择与报价；实际存款至少覆盖 Arbitrum 原生 USDC、两种跨链主币及两种跨链代币。不支持的组合记录配置差异，不向错误网络或合约转账。

• 存款准备折合 4.99 / 5 / 5.01 美元和超余额样本；提现准备可提现额、手续费、预留费及最小金额边界样本。记录操作前余额、地址和交易哈希，使用可承受损失的小额测试资金。

• 提现覆盖页面当前开放的 Ethereum / Avalanche / OP Mainnet / Arbitrum / Base / HyperEVM；另备旧通道配置，仅在该配置下验证 Arbitrum 旧桥通道。

• 本文覆盖从钱包转入、提现和对应账户历史；「链上收款」的地址、追踪及 Unifold 详情使用独立「Unifold 充值」用例；投资组合入口布局使用独立「投资组合 & 盈亏」用例。

1. 最大值为扣除必要网络费后的可用数量

1. 显示当前输入对应的预计 USDC 到账额；费用和价格影响可使其低于输入美元价值

2. 需要授权时显示授权并存款提示；已有足额授权时不强制重复授权

3. 不把跨链资产标为无需报价的直接存款

2. 迟到的旧响应不覆盖新值，不向旧账户或旧网络构建交易
