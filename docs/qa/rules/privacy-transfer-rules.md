# Zcash / Monero HD 钱包转账与隐私同步规则

## 1. 适用范围与确认依据

适用于 Zcash、Monero 的 HD 钱包；与 `transfer-chain-rules.md` 中 Zcash HW 的六条简化转账用例分开维护。依据为 2026-11-07 用户需求及本轮明确确认的恢复下限、上次同步时间和密钥授权口径。源码参考 app-monorepo `x@684c203c6f21edb6be863b695a0e1d80d6db1db2`，实现与需求冲突时沿用已确认需求。

## 2. 地址与转账

1. Zcash 仅 ZEC 主币，无代币；公开与隐私地址分别核对。沿用本链已确认的最小值 0.00000546 ZEC、中间测试值 0.01 ZEC 与 Max，覆盖四个地址方向；Max 核对确认页金额及实际费用。
2. 隐私使用与发送前同步至最新区块；接收后再同步核对入账。不开启、暂停或进行隐私同步，都不应阻塞公开地址、公开余额、公开历史及公开转账。
3. Monero 两条派生路径各执行真实转账，不能用同一个地址替代：标准 `m/44'/128'/0'`、Cake Wallet `m/44'/128'/0'/0/0` 为索引 0 的实例。其他索引替换账户索引，地址、余额及本地历史按派生账户归属。
4. Monero 在同步或发送需要密钥且未获得授权时唤起解锁；取消不广播、不扣款，也不启动该次需密钥的同步。再次授权后可继续；不要求持有有效授权时每轮后台同步重复弹出解锁。
5. 公开 → 公开交易可核对区块浏览器；涉及隐私的交易只核对本地历史，隐私地址位置显示「隐私」。不以外部浏览器可查询作为隐私到账条件。

## 3. 恢复与进度

| 网络 | 最早恢复日期 | 最低恢复区块 |
| --- | --- | --- |
| Zcash | 2026-07-28 | 3,428,143 |
| Monero | 2014-04-18 | 1 |

1. 首次默认恢复日期为设备当地今天，可按日期或区块恢复已有资产；更早日期、未来日期及无效高度不能提交。
2. 隐私地址在开启同步后才展示；接收及核对地址在尚未开启时提示先开启隐私地址同步。
3. 同步可暂停、继续；继续从保存进度推进，不重复累计余额和历史。显示本账户上次同步时间，离开页面或重启后保留；不将该时间与用户原先选择的恢复起点混为同一字段。
4. 当前同步状态在首页或主币详情页金额区域展示，不显示悬浮同步状态窗。

## 4. 账户管理与五个同步名额

1. 两个入口均可进入账户管理：「设置 → 钱包 → 隐私管理」、「钱包选择器 → 隐私同步」。比对同一钱包、同一网络、同一账户的同步状态；不能要求设置全局列表与钱包选择器过滤列表完全相同。
2. Zcash 与 Monero 合计最多五个不同地址同时同步。第六个地址静默开启，同时关闭一个旧地址的同步；无需用户选择替换或先删除旧数据。
3. 此规则也适用于同链已有五个地址的情况。旧地址具体淘汰顺序未确定，不断言一定替换最先添加或最久未使用的地址。
4. 跨链、同链名额场景集中在 Zcash HD 用例第 4 节，以 Zcash / Monero 参数分别执行，Monero 文档引用，避免重复维护。
