# Utility - 旅行模式

> 模块：Utility（通用）
> App 版本：6.7.0
> 日期：2026-10-29
> 测试端：iOS / Android

---

## 1. 需求背景

旅行模式用于在移动端临时隐藏 App 内个人信息，降低设备在特定场景下暴露钱包和使用记录的风险。开启或关闭模式时需要重启 App，关闭后恢复原有数据和 App 状态。

---

## 2. 功能描述

### 2.1 支持范围与入口

| 项目 | 说明 |
|-----|------|
| 支持平台 | 仅移动端支持，桌面端和 Web 端不提供旅行模式 |
| 入口 | 设置 → 安全 → 旅行模式 |

### 2.2 开启与关闭

| 项目 | 说明 |
|-----|------|
| 身份验证 | 开启和关闭均必须使用 PIN 码；不支持使用生物识别 |
| 重启 | 开启或关闭旅行模式后 App 自动重启 |
| 图标 | 开启旅行模式后替换 App 图标 |
| 关闭模式 | 关闭旅行模式时按产品流程完成 PIN 验证；关闭后恢复原有数据和 App 状态 |

### 2.3 隐私展示范围

| 项目 | 说明 |
|-----|------|
| 个人信息 | 旅行模式下不显示 App 内个人信息，包括钱包账户、收藏、浏览记录等 |
| 一级页面 | 旅行模式下允许点击和切换 App 一级页面 |
| 二级页面 | 不对旅行模式下的二级页面提出额外限制或要求 |

### 2.4 锁定相关能力

| 项目 | 说明 |
|-----|------|
| 锁定功能 | 旅行模式下锁定相关功能失效 |
| 关闭例外 | 关闭旅行模式时不要求生物识别，PIN 按关闭流程处理 |

---

## 3. 业务规则

| 规则项 | 规则描述 |
|-------|---------|
| 平台限制 | 旅行模式仅在 iOS / Android 提供 |
| 入口一致性 | 入口固定为设置 → 安全 → 旅行模式 |
| PIN 验证 | 开启和关闭均使用 PIN，不得使用生物识别替代 |
| 重启生效 | 开启或关闭后必须重启 App，模式状态以重启后的状态为准 |
| 图标替换 | 旅行模式开启后替换 App 图标，关闭后恢复原图标 |
| 信息隐藏 | 开启后隐藏钱包账户、收藏、浏览记录等 App 内个人信息 |
| 页面导航 | 一级页面可切换；二级页面不增加额外限制或要求 |
| 锁定失效 | 旅行模式开启期间锁定相关功能失效 |
| 关闭例外 | 关闭旅行模式时不要求生物识别，按关闭流程完成 PIN 校验 |
| 状态恢复 | 关闭后恢复原有数据和 App 状态 |

---

## 4. 已知风险

- 开启或关闭后的重启时序可能导致模式状态、图标和页面数据不一致。
- 隐藏范围涉及多个一级页面和个人数据类型，需防止账户、收藏或浏览记录残留展示。
- 锁定功能失效与关闭模式的 PIN 例外容易产生验证流程混淆。
