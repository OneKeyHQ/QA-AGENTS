# Perps - 投资组合与盈亏（Portfolio & PnL）（入口改造 + 图表/统计/风险）

> 需求来源：Perps 存款入口逻辑改造（显示投资组合与盈亏/Portfolio & PnL）
>  
> 覆盖端：桌面端 / Web 端 / iOS / Android（全端）  
> App 版本：  
> 生成时间：2026-03-26（2026-09-09 更新：新增 §2.9 资金费（Funding）图表类型）

## 1. 需求背景

- Perps 原“存款/Deposit”入口改造为“投资组合与盈亏（Portfolio & PnL）”入口（展示投资组合分析）。
- 不同端的入口形态不同：桌面端为弹窗浮层，移动端为全屏页面。
- 空账户/无可展示资产时，入口行为与展示逻辑有差异（桌面端空账户走充值引导弹窗）。

## 2. 功能范围

### 2.1 入口与路由

- 桌面端：点击 Perps 顶部的钱包徽标（或账户余额按钮）打开投资组合与盈亏弹窗浮层（双列布局）。
- 桌面端（空账户）：点击钱包徽标不打开分析弹窗，改为打开充值引导弹窗。
- 移动端：点击 Perps 顶部的钱包徽标跳转至 MobilePortfolioPage（全屏页面），不展示桌面端弹窗样式。
- 桌面端：账户面板图表入口可打开投资组合与盈亏，内容与顶部入口一致。
- 从不同入口进入，默认图表类型与默认时间维度一致。
- 页面/弹窗关闭、返回、重复进入后状态可重建；不出现白屏、遮罩残留、重复实例。

### 2.2 图表与时间维度

- 图表类型：
  - 账户价值/净值（Account Value）：展示历史净值/账户价值（折线/面积）。
  - 盈亏（PnL）：展示基线（baseline）数据，0 轴以上为绿色、0 轴以下为红色。
  - 资金费（Funding）：展示各时间桶的资金费净额柱状图（histogram），详见 §2.9。
- 图表类型切换时：图表、标题、单位、提示框（tooltip）数据随之切换。
- 时间维度：1D / 1W / 1M / All。
  - 切换时间维度时：请求参数、图表数据、X 轴范围同步更新。
  - 快速切换时：最终展示与最后一次选择一致。
- 边界数据：
  - 无数据、单点数据、极小波动、大幅波动：图表可显示，不闪退。
  - 不同端格式化/价格刻度/边距（formatter/priceScale/margins）表现一致（不截断、不压缩、标签不重叠）。
- 切换账户/切换币对/重新进入投资组合与盈亏后：图表数据刷新，不复用上一个账户的缓存数据。
- LightweightChart 新增基线/价格边距/自定义格式化（baseline/priceScaleMargins/custom formatter）后：Perps 其他图表使用场景不受影响。

### 2.3 PnL 与统计数据

- Total P&L 口径与 Hyperliquid 官方一致，包含 fees 与 funding。
- API 返回 pnlHistory 与 net deposits 后：净值、PnL、累计收益口径联动。
- 交易统计（Trading stats）展示字段（示例）：胜率（Win Rate）、盈亏因子（Profit Factor）、平均盈利（Avg Win）、平均亏损（Avg Loss）、手续费（Fees）、最常交易（Most Traded）。
- 统计计算覆盖：
  - 仅盈利成交、仅亏损成交、盈亏混合成交。
  - 无任何成交：Trading stats 为空态/默认态；Win Rate 条形图为灰色。
  - 仅充值提现、无交易记录：PnL 与统计展示不误算为交易收益。
- 性能：历史成交较多时加载不明显卡顿；避免重复请求。
- 异常兜底：服务端返回异常值、null、空数组、缺字段时不出现 NaN/Infinity。

### 2.4 账户健康与风险色

- Gauge：Leverage、Margin Used、Maintenance Margin、MMR 半圆仪表盘显示数值、单位、刻度与颜色。
- MMR 颜色阈值：
  - ≤ 40%：绿色
  - 40% ~ 70%：黄色
  - > 70%：红色
- 上述 MMR 颜色规则在以下模块保持一致：
  - Portfolio gauge
  - PerpAccountPanel
  - Mobile Ticker
- 边界：40%、70% 附近无错档、抖动或不一致。
- 极低风险、极高风险、无保证金数据：仪表盘可展示或兜底展示。

### 2.5 资金动作与返回

- Portfolio 内 Deposit/Withdraw 按钮可进入对应流程；目标 tab/路由正确。
- Mobile withdraw 场景 actionType 传递正确，进入后默认落在 withdraw tab。
- 从 Deposit/Withdraw 返回 Portfolio：状态恢复，不丢失当前账户上下文。
- DepositWithdrawModal 在 Desktop/Mobile 两端打开、关闭、切换 tab 行为不回归。

### 2.6 DashText 与提示组件

- Desktop：DashText 展示 Tooltip（hover/click 交互）。
- Mobile：DashText 展示 Popover（点击触发、关闭、遮罩、定位）。
- 多语言、深浅色、长文案、滚动、横竖屏切换下，Tooltip/Popover 不错位、不残留。

### 2.7 多端与回归

- Desktop 大屏：弹窗双列布局不重叠；小窗口：可滚动/自适应不遮挡操作区。
- Mobile：全屏纵向布局自然，不溢出。
- Web / iOS / Android / Desktop：同一账户数据下字段与关键数值一致。
- 语言切换：标题/按钮/统计项/tooltip 文案 key 不缺失、不泄漏。
- Perps Header 右侧入口、手续费弹层、账户面板、其他 LightweightChart 场景不回归。

### 2.8 盈亏资产类型筛选（全部 / 合约 / 现货）

> 新增（投资组合与盈亏接入现货数据）。

- 入口与显隐：
  - 盈亏资产类型下拉选择器（testID `perp-portfolio-pnl-type-selector`）**仅在图表类型 = 盈亏（PnL）时显示**。
  - 切换到净值/账户价值（Account Value）时，下拉隐藏，且筛选强制为「全部」。
- 选项与默认：
  - 选项：全部（all）/ 合约（perps，对应官方 perp）/ 现货（spot）。
  - 默认值 = 全部（all）。
  - 选中项展示勾选标记；触发器显示当前选中项标签（如「现货」）。
- 现货 / 合约的区分：按成交（fill）的标的用 `isSpotInstrument(coin)` 判定；现货 PnL 曲线 = 总盈亏曲线 − 合约盈亏曲线（nonPerpsPnlHistory = pnlHistory − perpsPnlHistory）。
- 筛选影响范围（**不仅图表，统计也联动重算**）：
  - 图表曲线：全部→pnlHistory；合约→perpsPnlHistory；现货→nonPerpsPnlHistory。
  - 总盈亏（Total P&L）：取对应类型曲线的最后一个值。
  - 交易统计（fillsStats，按类型过滤 fills 重算）：胜率（Win Rate）、盈亏因子（Profit Factor）、平均盈利（Avg Win）、平均亏损（Avg Loss）、已付手续费（Fees）、最多交易（Most Traded）、交易量（volumeUsd）、总交易次数（totalTrades）。
- 不受类型筛选影响（仅随账户 / 时间维度变化）：账户资产、可用、账户健康度（杠杆 / 已用保证金 / MMR）、净入金（netDeposits，仅随时间维度变化）。
- 时间维度联动：盈亏类型筛选与 1D/1W/1M/All 时间维度叠加生效，二者组合切换时图表与统计同步刷新。

### 2.9 资金费（Funding）图表类型

> 新增（PR #13163 / OK-61831：Perps 资金费历史与分析）。图表类型切换器新增第三项「资金费」，切换后图表区与右侧统计区整体切换为资金费视图。

- 入口与切换：
  - 图表类型 SegmentControl（testID `perp-portfolio-chart-type-selector`）选项顺序：净值 / 盈亏 / 资金费。
  - 切换到「资金费」后，盈亏资产类型下拉（`perp-portfolio-pnl-type-selector`）隐藏（仅盈亏类型显示）。
  - 时间维度 1天 / 1周 / 1月 / 全部 在资金费视图下继续生效。
- 图表：
  - 柱状图（histogram），以 0 为基线：正值（收取）绿色柱，负值（支付）红色柱；Y 轴为美元金额，X 轴为日期。
  - 数据源：Hyperliquid 用户资金费历史（userFunding），全量拉取后按时间维度分桶求和。
  - 悬停 / 触摸提示框显示时间与该桶净资金费金额。
- 图表下方汇总卡（不随时间维度变化，按记录时间固定口径统计）：
  - 24小时净额（Net 24h）、7天净额（Net 7d）、累计净额（Net all time）；正值绿色、负值红色、0 为默认色。
- 右侧统计区替换为资金费分布（PerpFundingBreakdown），账户资产 / 可用 / 存款 / 提现区块保持不变：
  - 「累计收取（Total received）」卡：标题 + 该时间维度内收取总额 + 环形图 + 各市场行（币种、占比 %、金额）。
  - 「累计支付（Total paid）」卡：同上，统计支付方向。
  - 各市场按金额降序，最多展示 5 个市场，其余合并为「其他（Others）」一行。
  - 悬停 / 点击某一行或环形分段时高亮该市场，其余行淡化。
  - 分布卡随时间维度变化（仅统计该维度起点之后的记录）。
- 状态：
  - 加载中：图表区与分布卡显示骨架屏。
  - 该时间段无资金费记录：图表区显示「此时间段内暂无资金费记录」；分布卡对应方向无记录时显示灰色空环 + 同一文案。
  - 拉取失败：图表区与分布卡显示「失败」+「重试」按钮（testID `perp-portfolio-funding-retry` / `perp-funding-breakdown-retry`）；汇总卡显示 `--`；同一账户此前已成功的数据在刷新失败时保留。
- 刷新与缓存：资金费历史仅在资金费视图激活时请求；同一账户结果缓存；长时间停留每小时自动刷新一次；切换账户后重新拉取，不复用上一账户数据。
- 多端：桌面端双列布局（左图表、右账户资产 + 分布卡）；移动端纵向布局（账户资产 → 图表 → 分布卡），SegmentControl 三项文案随语言切换。

### 2.10 底部面板「资金费」历史列表（同批新增，用例并入本文档）

- 入口：桌面端底部面板 tab「资金费」（位于成交历史与账户之间）；移动端「交易历史」弹层内同名 tab；行情栏资金费率悬浮层「查看资金费分析」打开投资组合并默认资金费图表类型。
- 列表：时间（日期 + 时间）/ 市场 / 数量（绝对值 + 币种）/ 方向（多绿 空红，0 显示 --）/ 资金费（+绿 −红）/ 费率（≥ 0.01% 四位小数，< 0.01% 六位小数）；按时间倒序；每页 20 条。
- 筛选：方向（全部 / 多 / 空）+ 市场（全部 + 账户产生过记录的市场，字母序，支持搜索）；叠加生效；切换筛选回到第 1 页；切换账户后不存在的市场筛选自动清空。
- 空态：无记录「暂无资金费 / 资金费记录将在此显示。」；筛选无匹配「没有匹配的资金费 / 请尝试其他筛选条件。」；失败显示「失败」+「重试」。
- 导出：「导出数据」按当前筛选导出全部记录（不受分页限制）为 CSV，文件名 `perp_funding_history_yyyyMMdd-HHmmss.csv`，列头随语言，时间为 ISO 8601；成功 / 无数据 / 失败分别 toast；无账户时禁用；导出中重复点击忽略；以 = + − @ 开头的文本加 `'` 前缀防公式注入。
- 数据：与投资组合资金费视图共用同一历史数据源（按需请求、同账户缓存、每小时刷新）；列表净和 = 投资组合累计净额。

## 3. 已知风险点（用于测试聚焦）

- 入口与空账户分支：Deposit 引导与 Portfolio 弹窗切换逻辑。
- 图表 formatter 与 margins：多端一致性与标签重叠/截断。
- 统计计算：0/空数组/null/缺字段，避免 NaN/Infinity。
- 风险阈值边界：40%/70% 颜色切换与抖动。
- 频繁切换筛选/账户：缓存复用与竞态导致的旧数据残留。
- 资金费视图：①切换到资金费后盈亏类型下拉需隐藏、右侧统计区需整体替换为分布卡且账户资产区块不变；②24h / 7d / 累计净额不随时间维度变化，而柱状图与分布卡随时间维度变化，二者口径易混淆；③收取 / 支付方向拆分、Top 5 + 其他合并、占比之和 = 100%；④空记录 / 拉取失败 / 切换账户时的空态、重试与旧数据残留。
- 盈亏资产类型筛选：①下拉仅在 PnL 图表类型下出现，切回净值需隐藏并强制 all；②现货/合约拆分口径（isSpotInstrument）正确，现货 = 总盈亏 − 合约盈亏；③切换类型时图表、总盈亏、交易统计需同步联动，无旧数据残留；④无现货/无合约成交时对应类型显示空态/默认态，不出现 NaN/Infinity。
