# Perps - 仓位止盈/止损

> 需求来源：[OK-67523](https://onekeyhq.atlassian.net/browse/OK-67523)、[热更讨论](https://onekeygroup.slack.com/archives/C026693UM62/p1795015434349089)
> 实现范围：[PR #14610](https://github.com/OneKeyHQ/app-monorepo/pull/14610)，含 [#14645](https://github.com/OneKeyHQ/app-monorepo/pull/14645) 和 [#14646](https://github.com/OneKeyHQ/app-monorepo/pull/14646)
> 测试端：iOS / Android / Desktop / Web / Extension；图表定价入口在支持该菜单的大屏端验证。

1. 持仓列表打开弹窗时，尚未设置的止盈和止损价格及 ROE 留空。图表入口只预填指定侧，保留已有委托，只能补设缺失侧。
2. 止盈与止损各展示四档 ROE 快捷选项，幅度为 5%、10%、25%、50%。止盈展示正号，止损展示负号。选档仅填写当前侧，按开仓价、持仓方向、杠杆与价格精度换算触发价，重复点击不累加。支持只设置一侧或同时设置两侧。
3. 弹窗显示中间价。多仓止盈必须高于实时中间价，止损必须低于，空仓相反。等价或错侧提示正确方向，提交前再次校验最新中间价。已有整仓委托显示自身触发方向。德语的「低于中间价」使用 `unter dem Mittelpreis`。
4. 图表止盈/止损入口由所选价位与中间价的关系决定，盈亏仍按开仓价计算。有效止盈预计亏损时，将预期利润标签、负数金额及解释一并显示为黄色，多仓解释触发价低于开仓价，空仓解释触发价高于开仓价。该提示不阻塞确认。盈利、盈亏平衡、无触发价或触发价无效时不显示亏损提示。
5. 窄屏可滚动浏览弹窗并操作快捷档、部分仓位数量和滑杆，确认区不遮挡控件。委托数量与提交时的设置一致。开仓表单的附带止盈/止损沿用原有预填规则。
