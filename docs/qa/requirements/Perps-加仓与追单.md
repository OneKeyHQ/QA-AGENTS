## 📋 需求背景

### 需求简介
优化快捷交易流程：
1. **加仓**：在「当前持仓」列表行内直接对已有持仓加仓，无需回到主交易面板
2. **追单**：在「当前委托」列表行内一键将未成交限价委托的价格改到当前同侧最优价，并以 ALO（PostOnly）挂单

### 影响范围
- **测试端**：iOS / Android / Extension / Desktop / Web（全端）
- **数据源**：Hyperliquid

## 🎯 功能描述

### 功能点 1：持仓加仓（Add Position）

**入口**：「当前持仓」每行操作区新增「加仓」按钮（位于 市价/限价 平仓按钮之前），testID `position-add-button`。

**弹窗表单**：
- 方向**锁定为当前持仓方向**（多仓加多、空仓加空）
- 订单类型：市价（默认）/ 限价
- 限价价格默认预填当前中间价（mid price），可修改
- 数量：手动输入 + 百分比滑杆（上限 = 该方向 maxTradeSz），单位跟随交易面板 sizeInputUnit 偏好（token / usd / margin）
- 可选止盈/止损（TP/SL），按百分比种子值预填
- 杠杆沿用当前持仓杠杆

**校验**（按钮可点、点击后 Toast，不静默禁用）：
| 错误 | 条件 |
| --- | --- |
| invalidSize | 数量为空 / ≤0 |
| invalidPrice | 限价价格为空 / ≤0 |
| insufficientMargin | 数量 > maxTradeSz |
| minimumOrder | 数量 × 价格 < $10 最小名义价值（提示按当前 size 单位换算） |

**范围守卫**：弹窗打开期间发生 账户切换 / 持仓已平 / 方向反转 → 提交被拦截；需已启用交易。

**结果**：市价加仓成交后持仓数量增加、开仓均价加权更新；限价加仓生成普通限价委托（reduceOnly=No）进入「当前委托」。

### 功能点 2：委托追单（Chase Order）

**已确认更新**：2026-11-11，需求 [OK-63729](https://onekeyhq.atlassian.net/browse/OK-63729)，PR #13835；当前源码核对 OneKeyHQ/app-monorepo x@e1fb3420378298d6e560eac5e3a71b8eb2407c84。

**入口与可用范围**：当前委托中的合约普通 Limit、GTC / ALO、非触发单及非持仓止盈止损单、剩余数量大于 0 时显示追单；IOC、条件单、现货及 TWAP 不支持。

**目标价与确认**：买单取买一，卖单取卖一。弹窗目标价随有效同侧行情更新，显示修改后有效期 ALO；确认并通过交易校验后重新取价，跳过弹窗同样取提交前最新价。无法获取有效价格时拦截。弹窗取消不改单；跳过确认偏好与普通下单共用。

**执行结果**：限价单统一按 ALO（PostOnly）改单，保留方向、只减仓及最新剩余量；不要求立即成交。盘口变化导致提交价会吃单时可被 PostOnly 拒绝，界面刷新交易所最终状态。同价 ALO 不重复改单、保留排队优先级；同价 GTC 仍转为 ALO。执行中同笔防重，账户变化拦截。

**订单保护**：已成交或撤销的订单不重建；旧单撤销失败时不额外挂新单，不产生重复委托或重复成交。

## 📐 边界条件

| 场景 | 处理 |
| --- | --- |
| 加仓时账户切换 / 持仓已平 / 方向反转 | 拦截提交，提示市场数据变化 |
| 加仓金额 < $10 名义价值 | Toast 最小金额提示 |
| 追单时 BBO 不可用 | 报错「当前最优价不可用」，不改单 |
| 追单执行中账户切换 | 报错「交易账户已变更」，不改单 |
| 追单期间订单完全成交 / 已撤销 | 改单失败，提示错误，列表状态刷新 |
| 重复点击追单 | 同一订单执行中禁用，不重复提交 |
