## 📋 需求背景

### 需求简介
Perps 存款新增 **Unifold 链上收款**通道：用户可选择不同代币和不同网络，向生成的存款地址转账，资产经第三方兑换后存入 Hyperliquid 永续合约账户（HyperCore）。App 只与 OneKey wallet-service 通信，不直连供应商；UI 用 OneKey 组件自建。

### 影响范围
- **测试端**：iOS / Android / Extension / Desktop / Web（全端；移动端选择器流程与桌面端不同）
- **数据源**：OneKey wallet-service（Unifold 通道），目标网络 HyperCore
- **开关**：服务端远程开关 `perpConfigCommon.unifoldDepositEnabled === true` 时才显示入口；关闭/缺失/未加载完成时走原有存款流程（fail-closed）

## 🎯 功能描述

### 功能点 1：入口

- 方式选择标题为「充值至合约账户」。钱包卡片标题为「OneKey 钱包」或「已连接钱包」，说明为「从钱包余额转入」。另一张卡片显示「交易所或其他钱包」和「获取充值地址或二维码」。两张卡片使用对应图标，文案覆盖 19 种语言。
- 「账户历史」tab 区域新增「**链上存款**」按钮 → 打开链上存款记录
- 宽屏通过底部「跟踪你的存款进度」进入记录，iOS / Android / 窄屏 Web 通过右上角历史图标进入，移动布局无底部重复入口。记录页「存款」返回转入页。

### 收款账户模式与到账目标（6.8.0）

2026-11-27 用户确认本轮维护建议，依据 [OK-67767](https://onekeyhq.atlassian.net/browse/OK-67767) / [PR #14728](https://github.com/OneKeyHQ/app-monorepo/pull/14728)。

- `unifiedAccount` 到 HyperCore Spot USDC；`portfolioMargin`、`disabled`、`default`、`dexAbstraction` 到 Perp USDC，用户无需手选目标。
- 新会话先读取当前收款地址的最新模式，再加载对应目标的支持资产和地址。查询中、失败或未知模式时不显示可转账地址，不猜测为普通模式，并提供可恢复的重试流程。
- 查询期间切换收款账户，丢弃旧结果并按新地址重查。当前固定旧收款地址的中断与此预期不符，保留为缺陷验证，不改成必须关闭重进的需求。
- 同一账户在地址展示前切模式，等待新目标目录和地址匹配；已展示后不静默换地址，提示重进新会话。原已发起充值继续按原目标追踪。
- 断线或资格待复核时隐藏地址、二维码并阻止复制，同地址重连也重新复核。历史显示每笔实际目标，旧记录缺目标字段时按可用真实币种信息展示，不按当前模式猜测。
- 两种目标均需OneKey后端支持资产、地址生成和真实到账联调；参数、官方Demo或任务关闭不能代替到账证据，本批文档维护未执行转账。

### 功能点 2：代币与网络选择（转入加密货币）

- 代币下拉：展示支持代币（USDC / BTC / SOL / HYPE / USDe / BTCB / UBTC 等），每项显示支持网络数（如「6 个网络」）
- 网络下拉：展示每个网络的**最低存款金额**（USDC：Ethereum $10，Base / Arbitrum / Polygon / Optimism / BSC $3 等），当前选中项带 ✓
- 切换代币/网络后：QR 码、存款地址、存款路径、最低金额同步刷新；支持资产与选择会缓存，同一代币+网络重复选择不重新加载地址/QR
- 移动端：先弹代币选择器再进转入页，代币/网络选择在同一 modal 流内完成；瞬态选择器不参与返回导航

### 功能点 3：转入页信息

- **存款地址**：完整展示 + 复制按钮；QR 码中心带所选网络 logo，扫码结果与展示地址一致；地址对应**当前活跃 Perps 账户**（服务端回显校验，不一致则拒绝展示）
- 合约信息从带下划线的「已选代币」打开。宽屏悬停显示可交互提示，移动布局点按显示「代币合约」弹层，保留风险提示及当前合约地址复制。
- 「最低存款」位于详情卡首行，在「存款路径」上方，金额随所选网络配置更新，提示保留低额累计兑换说明。
- 明细保留存款路径（所选代币 → 按收款模式确认的 Spot USDC / USDC (Perp)）、第三方兑换手续费 0.25%、处理时间及最大滑点，去掉「价格影响」。二维码定位图案保持完整，扫码结果与显示地址一致。
- 「条款」「帮助」链接

### 功能点 4：到账与最小金额语义

- 单笔 ≥ 所选网络最低金额：兑换后存入 Perps 账户，可用余额增加
- 单笔 < 最低金额：**不立即到账**；同一存款地址可多次转账（standing inbox），累计总额达到最低金额后**合并到账**
- 非 USDC 代币按已确认路径兑换为 Spot USDC / USDC (Perp)，到账金额扣除第三方手续费，收到币种对应本笔实际目标。
- 状态通知：转入页打开时，移动布局的历史角标反映待处理状态，宽屏进度卡片计入近期终态。宽屏进度卡片可见期间完成的存款，关闭后不重复提示。关闭后完成的存款由后台通知，失败提示可附会话参考编号。

### 功能点 5：链上存款记录与详情

- 页面标题为「链上存款」。页面引导卡显示「加密货币转入记录」、状态说明和「存款」按钮。列表项显示目标代币图标、状态角标、状态、时间及美元金额。记录详情标题为「存款详情」，按端适配卡片展示。
- 详情（已完成）：发送数量 / 收到数量 / 美元价值 / 来源网络 / 目标网络 HyperCore / 参考编号（可复制）/ 存款交易 hash / 完成交易 hash（可跳区块浏览器）
- 详情（处理中）：收到数量显示 `--`（不显示 0）；超时显示提示条「处理时间比平时更长」+「帮助」按钮
- `delayed` 状态渲染为进行中，**不渲染为失败**（服务端为状态权威）
- 宽屏进度卡片计入未结束、以及最近 2 分钟内已结束的记录。移动布局右上角绿色角标仅计待处理。0 笔无数字，1–99 显示实际笔数，超过 99 显示 99+。
- 金额格式：字符串 + BigNumber 格式化；不可用显示 `--` 不显示 0；极小额显示 `<0.00000001` 不折叠为 0

### 边界说明

- 受限状态（sanctioned / 地区限制 / 功能停用 / 目标不匹配）为粘性拦截，不可被后续状态覆盖
- 地址创建失败自动重试（5s）；执行列表 3s 轮询，单次失败不弹全局错误 toast
- Cash 渠道（银行卡/交易所/Cash App）不在本期范围
