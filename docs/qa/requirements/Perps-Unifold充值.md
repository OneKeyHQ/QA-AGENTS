## 📋 需求背景

### 需求简介
Perps 存款新增 **Unifold 链上收款**通道：用户可选择不同代币和不同网络，向生成的存款地址转账，资产经第三方兑换后存入 Hyperliquid 永续合约账户（HyperCore）。App 只与 OneKey wallet-service 通信，不直连供应商；UI 用 OneKey 组件自建。

### 影响范围
- **测试端**：iOS / Android / Extension / Desktop / Web（全端；移动端选择器流程与桌面端不同）
- **数据源**：OneKey wallet-service（Unifold 通道），目标网络 HyperCore
- **开关**：服务端远程开关 `perpConfigCommon.unifoldDepositEnabled === true` 时才显示入口；关闭/缺失/未加载完成时走原有存款流程（fail-closed）

## 🎯 功能描述

### 功能点 1：入口

- 存款弹窗新增「**链上收款**」选项（副标题"将其他交易平台/钱包资产存入永续合约账户"，展示支持代币图标 +N），与「从 OneKey Wallet 转入」并列
- 「账户历史」tab 区域新增「**链上存款**」按钮 → 打开链上存款记录
- 转入页底部「**跟踪你的存款进度**」→ 跳转链上存款记录；记录页头部「存款」按钮 → 返回存款流程

### 功能点 2：代币与网络选择（转入加密货币）

- 代币下拉：展示支持代币（USDC / BTC / SOL / HYPE / USDe / BTCB / UBTC 等），每项显示支持网络数（如「6 个网络」）
- 网络下拉：展示每个网络的**最低存款金额**（USDC：Ethereum $10，Base / Arbitrum / Polygon / Optimism / BSC $3 等），当前选中项带 ✓
- 切换代币/网络后：QR 码、存款地址、存款路径、最低金额同步刷新；支持资产与选择会缓存，同一代币+网络重复选择不重新加载地址/QR
- 移动端：先弹代币选择器再进转入页，代币/网络选择在同一 modal 流内完成；瞬态选择器不参与返回导航

### 功能点 3：转入页信息

- **存款地址**：完整展示 + 复制按钮；QR 码中心带所选网络 logo，扫码结果与展示地址一致；地址对应**当前活跃 Perps 账户**（服务端回显校验，不一致则拒绝展示）
- **代币合约**（虚线下划线）：悬浮/点击显示警示"代币合约地址并非你的存款地址，向该地址转账可能导致资产损失…" + 当前网络代币合约地址（可复制）
- **最低 $N**（黄色高亮）：悬浮显示"所选网络要求的最低存款金额。"
- 明细字段：存款路径（{token} → USDC (Perp)）/ 第三方兑换手续费 0.25% / 处理时间 / 最大滑点 / 价格影响
- 「条款」「帮助」链接

### 功能点 4：到账与最小金额语义

- 单笔 ≥ 所选网络最低金额：兑换后存入 Perps 账户，可用余额增加
- 单笔 < 最低金额：**不立即到账**；同一存款地址可多次转账（standing inbox），累计总额达到最低金额后**合并到账**
- 非 USDC 代币按存款路径兑换为 USDC (Perp)，到账金额扣除第三方手续费
- 状态通知：转入页开着时在面板内显示每笔执行的状态卡片；关闭后由后台轮询接管，终态变化通过标准 Perps toast 通知（两者不重复通知）；失败时 toast 提示联系支持并附参考编号

### 功能点 5：链上存款记录与详情

- 列表头部：「加密货币转入记录 / 跟踪处理中、已完成或需要处理的存款。」+「存款」按钮
- 列表项：代币+网络 logo、状态（存款已完成 / 处理中）、时间、美元金额
- 详情（已完成）：发送数量 / 收到数量 / 美元价值 / 来源网络 / 目标网络 HyperCore / 参考编号（可复制）/ 存款交易 hash / 完成交易 hash（可跳区块浏览器）
- 详情（处理中）：收到数量显示 `--`（不显示 0）；超时显示提示条「处理时间比平时更长」+「帮助」按钮
- `delayed` 状态渲染为进行中，**不渲染为失败**（服务端为状态权威）
- 追踪卡片徽标计数 = 非终态执行数 + 近期完成的执行数
- 金额格式：字符串 + BigNumber 格式化；不可用显示 `--` 不显示 0；极小额显示 `<0.00000001` 不折叠为 0

### 边界说明

- 受限状态（sanctioned / 地区限制 / 功能停用 / 目标不匹配）为粘性拦截，不可被后续状态覆盖
- 地址创建失败自动重试（5s）；执行列表 3s 轮询，单次失败不弹全局错误 toast
- Cash 渠道（银行卡/交易所/Cash App）不在本期范围
