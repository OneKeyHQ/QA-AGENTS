# Perps - 分时委托（TWAP）与分段委托（Scaled Orders）

## 1. 需求来源与范围

- 原始需求：2026-06-03 分时 / 分段委托；本次增量：Jira OK-59156「Perps - TWAP 订单升级」（2026-10-27 读取）。
- 来源地址：https://onekeyhq.atlassian.net/browse/OK-59156
- 规则：`docs/qa/rules/perps-rules.md` §6；用例：`docs/qa/testcases/cases/perps/2026-06-03_Perps-分时分段委托下单.md`。
- 测试端：iOS / Android / Desktop / Extension / Web；永续与现货共用 TWAP 表单，保留各自资金和字段差异。
- 按需求及本次用户确认的行为确定验收口径。核对版本 x@69a579bad8af76dadf8eeaa76bea76fe678bc5d5，PR #13833 / #13960；SDK 升级 PR #13832。

## 2. 已确认 TWAP 升级需求

1. 升级 Hyperliquid SDK，支持 `details` 与最长 7 天；仅升级到仍限制 24 小时的版本不足以覆盖需求。
2. 支持触发价格、买入最高价 / 卖出最低价；触发后执行、达到停止价后停止剩余执行，保留实际已成交部分。
3. 执行时长最长 7 天，保留原最短 5 分钟；原 24 小时以上的合法时长可创建。
4. 展示子订单估算结果，标签沿用「每笔子订单金额」，表单与确认弹窗信息统一。
5. 总金额最低 100 USDC，按币种 / USD / 成本单位换算键盘和 Toast 提示。
6. 修复等待触发、执行中、已结束订单的状态、计时及分页。

## 3. 既有功能与本次替换

- 分时委托的只减仓、随机执行、Agent 钱包签名、数量单位切换与现货差异继续回归；只减仓仍需满足 TWAP 新最低金额。
- 删除旧 TWAP「最长 24 小时」「每片不足 10 美元直接拦截」「固定 30 秒严格等量与固定笔数」的现行预期。
- 分段委托保持价格区间、2–100 笔、固定 / 递增分配及每笔最低 $10；合约提供 GTC / IOC / ALO，现货固定 GTC。
- 分段委托属于普通限价单，进入主当前委托，可逐笔 / 全部撤销；不进入 TWAP 专属列表，不提供整组终止。
- 交易类用例使用有余额 HD 钱包真实执行；观察账户只能用于只读数据，不能替代交易验收。

## 4. 进阶交互与边界规则

以下行为已于 2026-10-27 由用户确认，对应用例见 §20：

- 6h / 12h / 24h / 7d 快捷项、超限归一、非法输入过滤、关闭进阶及切换方向清理策略。
- 以标记价判断触发方向、相等价拦截；买入停止价严格高于、卖出严格低于触发价或无触发时的标记价；确认后跨价拒绝。
- 先规整数量再判断 100 USDC、最小数量向上取整、快捷填入以及币种 / USD / 成本提示。
- 子订单估算公式、缺失中间价占位、「每笔子订单金额」展示币种数量。
- 等待不计时、激活时间缺失占位、触发但零成交仍活跃、终态冻结、同币种按订单区分、旧记录兼容及迟到事件。
- 新价格列与空值、等待中终止及历史去重分页。
- 进阶两项留空按基础委托执行；确认提交中拦截重复点击。

按产品最新确认，表单与确认弹窗保留「每笔子订单金额」标签及现有金额说明文案；撤回此前改为「子订单数量」的文案预期。估算数值与币种单位仍按既有计算及展示规则校验。

## 5. 接口自动化覆盖（建议，未生成 / 未执行）

- 基础 TWAP 不携带 `details`；进阶组合为仅触发 / 仅停止 / 两者皆有 / 两者皆空。
- `details.t` 为触发价与方向或 null，`details.s` 为停止价或 null；具体 wire 字段与校验见模块规则 §6.3.3。
- 同时覆盖 SDK 10080 分钟、最低总额与价格精度、只减仓、现货、确认后行情跨价、事件归档 / 去重。
- 现有 API / UI 自动化未找到对应 TWAP 业务用例，本轮交付不计为自动化覆盖。
