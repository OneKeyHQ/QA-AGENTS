> 模块：Prime  
> 来源：[OK-67058](https://onekeyhq.atlassian.net/browse/OK-67058) 当前描述；产品回复见同一 issue 评论。关联 Test：[OK-67680](https://onekeyhq.atlassian.net/browse/OK-67680)。布局参考 [PR #14502](https://github.com/OneKeyHQ/app-monorepo/pull/14502)、实现 [PR #14647](https://github.com/OneKeyHQ/app-monorepo/pull/14647)。

## 1. 需求背景

从钱包「更多」进入补贴中心，用户可以了解 Tron 免费能量和 Gas Account 多链网络费补贴的使用条件，查看自己的 OneKey ID 累计节省的网络费及逐笔明细。权益绑定 OneKey ID，不要求 Prime 订阅。

## 2. 功能描述

### 2.1 入口与未登录

| 项目 | 说明 |
|-----|------|
| 主入口 | 钱包「更多」→「补贴中心」（Kahn 确认入口放「更多」） |
| 既有入口 | 旧领取入口保留，改跳补贴中心；若入口带账户参数，则领取账户固定并打开领取面板 |
| 未登录 | 打开即可查看适用范围；登录 OneKey ID 后可使用补贴，也可继续自付网络费 |
| 桌面未登录 | 左侧登录，右侧展示两类补贴及使用步骤 |
| 移动未登录 | 首页展示登录入口和「可享补贴」，下滑查看使用步骤 |

### 2.2 已登录首页

| 项目 | 说明 |
|-----|------|
| 统计主体 | 按当前 OneKey ID 统计累计节省金额和已补贴交易笔数；两端同一 ID 看到相同金额和笔数 |
| 桌面 | 侧栏显示累计金额、两类补贴入口和记录笔数；默认右侧展示 Tron 领取详情 |
| 移动 | 顶部显示累计金额、交易笔数和补贴类型数；下方是「我的补贴」和最近 6 笔记录 |
| 暂无使用记录 | 显示零金额和零笔（`$0.00` / 0 笔），补贴入口仍可用；桌面侧栏记录数为 0、右侧空状态；移动记录区显示「暂无补贴记录」 |

### 2.3 全部补贴记录

| 项目 | 说明 |
|-----|------|
| 行内容 | 每笔展示交易名称、补贴类型图标、网络、日期和实际节省金额，最新交易在前 |
| 交易名称 | 产品确认：Gas 按 `ga.scenario`，`send` 显示「转账」，缺值或不认识显示「Gas 赞助交易」；Tron 显示「免费领取能量」或「兑换码兑换」 |
| 桌面 | 选择侧栏「补贴记录」，在右侧翻页 |
| 移动 | 超过 6 笔时出现「查看更多」，进入可分页的全部记录 |
| 列表窗口 | 历史列表为近 90 天；侧栏「补贴记录 N」取首页 `data.total`（0 表示无记录，null 时保留列表并隐藏笔数） |
| 汇总与列表 | 汇总可为全历史，列表为近 90 天，两个数字对不上是预期 |

### 2.4 Tron 免费能量

| 项目 | 说明 |
|-----|------|
| 每日领取 | 选择接收能量的 Tron 账户；每个地址每日可领取一次，GMT+8 零点重置 |
| 桌面 | 右侧「每日领取」面板展示今日库存、地址月剩余次数和领取按钮 |
| 移动 | 点「去领取」打开同样的领取面板 |
| 今日已领取 | 领取后提示在 10 分钟内使用；桌面侧栏显示截止时间、按钮变为「已领取」；移动首页卡片提示最晚使用时间、面板显示「已领取」 |
| 今日库存已领完 | 当日库存为零，用户仍可使用兑换码；按钮显示「已领完」 |
| 本地址月上限 | 即使当日仍有库存，也按所选地址的月额度判断领取资格；按钮提示月额度已达上限 |
| 账户待激活 | 使用所选 Tron 账户前需先激活；操作区提示「充值 ≥ 0.1 TRX」，领取面板底部提供充值入口 |
| 兑换码 | 能量发至所选 Tron 账户；兑换码为空时兑换按钮不可用；成功后清空输入框并显示「兑换成功」 |

### 2.5 Gas Account 与使用说明

| 项目 | 说明 |
|-----|------|
| 使用方式 | 登录后，符合条件的转账或兑换自动抵扣网络费 |
| 验收口径 | 支持范围和实际补贴金额以交易确认页为准；超出部分自行支付 |
| 桌面 | 选择左侧多链补贴，在右侧查看支持网络、适用操作和规则 |
| 移动 | 点「查看详情」打开多链网络费补贴说明 |

## 3. 数据口径与验收

| 项目 | 预期 |
|-----|------|
| 累计金额与交易笔数 | 同一 OneKey ID 在两端看到相同的金额和笔数。累计金额为全部已补贴交易实际节省金额之和，翻页不影响总额 |
| Tron 领取与使用 | 领取能量时保留领取记录，实际用于交易后才计入金额和笔数，同一笔补贴只计算一次 |
| 金额折算 | 产品与后端确认 Tron 能量折算为节省金额的方法、计价币种和折算时点前，不验收具体折算公式 |

## 4. 已知范围与评论差异

- 交易确认页的 TRON 领取入口与转账前自动领能量仍走原路由打开本页。
- 多语言 key 未作为本期验收。
- 评论中 Kahn 曾接受首页两格「GA 已结算 N 笔」「Tron 能量申请已受理 M 次」；**当前描述**改为累计节省金额 + 已补贴交易笔数（移动另有补贴类型数）。用例按当前描述验收。
- 评论中赞助成本不宜称「节省」、缺额不显示 0：适用于**单笔**缺证据金额（显示「结算中」或「—」）。无记录总览按描述显示 `$0.00` 和 0 笔。
