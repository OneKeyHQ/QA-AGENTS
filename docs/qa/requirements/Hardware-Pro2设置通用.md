# Pro2 - 设置 - 通用

> 需求依据：OK-55000 原用例及 2026-11-07 用户确认；源码参考为 firmware-pro2 main，d2b16b0f4b99a3380c2f87334226f0c0223ad402。
> 范围：Pro2 设备端「设置 → 通用」，不套用 App 设备管理设置的硬件确认流程。

## 1. 语言与动画手势

1. 支持中文与 English 切换，通用设置及子页面的标题、设置名称、说明随所选语言显示。
2. 动画默认开启；开启时页面切换有过渡动画，关闭时直接切换，导航结果一致。
3. Home Bar只在从主屏进入设置等一级菜单或设备App首页时显示，2秒后消失；进入通用及其他子菜单不显示，也不重新触发2秒显示。不把“每个子页面进入后显示2秒”作为预期。
4. 动画开启、关闭均覆盖一级Home Bar显示/隐藏、底部上滑退出、从子页面的左边缘/页面中部向右侧滑返回及列表滚动；关闭动画不禁用手势。普通子页面没有Home Bar仍可底部上滑退出。
5. 按受测固件主屏全部菜单/App及各可达普通子页清单逐页点击、上滑退出和重入，记录覆盖；每页不得半程滞留、闪烁、叠页、触摸失效、闪退或设备重启。受保护的签名、PIN、备份或授权流程保留既有退出限制，不强制上滑越过保护；这些流程的确认/取消按各自操作处理。
6. 普通页面手势滑动到一半时，由App发起地址核对或测试签名请求，新事件应打断动画并结束旧触摸，旧手势呈松开还原状态；未完成的导航还原，已经完成的导航保留完整终态，不停在中间。动画关闭时同样清理旧手势状态。
7. 覆盖半程按住、接近完成松手及刚完成等时机，以及滑条拖动、列表滚动。新请求完整显示且不继承旧触摸，松手不得误确认/误取消新请求；处理后原页面可再次交互，无闪烁或闪退。控件结束按住状态不等于撤销拖动时已生效的设置数值。

## 2. 触控与震动

1. 震动默认开启，覆盖键盘输入/删除、按钮、开关、滑动签名开始/未完成/完成、长按签名开始/取消/完成。
2. 长按中取消停止震动，重新操作重新反馈，结束后无持续残留震动。
3. 关闭震动后，上述操作均无震动；三种签名手势仍可完成，长按绿色边框动画保留。重新开启后恢复对应触感。
4. 双击唤醒默认开启；开启时熄屏后单击不亮屏、双击亮屏，关闭时触摸不唤醒，电源键仍可唤醒。

## 3. 显示与自动锁定

1. 亮度范围为 10%～100%，最低亮度下页面仍可辨识。
2. 自动锁定选项为 30 秒、1/2/5/10/30 分钟、永不；自动关机选项为 1/2/5/10 分钟、永不。
3. 默认空闲 1 分钟锁定，锁定后空闲 5 分钟关机；另覆盖 30 秒锁定加 1 分钟关机、永不锁定加 1 分钟关机。空闲条件为无 USB/蓝牙通信且无用户触摸，计时预期沿用原 Jira 验收口径。
4. 型号名称与蓝牙 ID 默认开启；锁屏时随开关显示/隐藏。
5. Portfolio 功能使用已有独立用例，本文件不重复其数据同步与资产展示场景。

## 4. 磁吸保护壳

1. 检测默认关闭。开启后合盖熄屏、开盖亮屏；关闭后保护壳不触发熄屏或亮屏。
2. 无线充电可充电与亮屏，不因充电器磁场反复闪屏。
3. 采用新版磁场干扰屏蔽与恢复：持续磁场下（如笔记本电脑触控板侧边）重复手动唤醒触发干扰屏蔽后可保持亮屏；移开磁场并恢复检测后，保护壳联动可再次使用。
4. 本批不沿用旧固定“3 秒”时限，也不将内部 800ms、2 秒采样计时直接写成端到端验收时间。

## 5. 声音与设置保留

1. 声音默认开启；开启时显示音量滑条及交易/二维码提示开关，关闭时隐藏并停止对应提示音。
2. 拖动音量后松手播放试听声，较高音量试听声大于较低音量。
3. 交易提示音开启时在签名完成页发出两声提示，关闭时无提示；Turbo 确认遵循该开关。二维码提示音开启时完整识别后两声提示，关闭时无提示。
4. 语言、动画、震动、双击唤醒、亮度、自动锁定/关机、型号名称与蓝牙 ID、磁吸及声音各项分别覆盖退出重入与常规重启后保留，并验证对应操作继续采用保存值。
