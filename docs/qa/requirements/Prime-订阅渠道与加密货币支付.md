## 1. 需求背景

Prime 按客户端安装渠道提供商店内购、信用卡和加密货币支付。加密货币支付需要同时覆盖 App 内转账、Infini 外部钱包、订单有效期、Pending 回访、部分付款和续订限制。

## 2. 客户端订阅渠道

| 客户端包 | 支付方式 |
|---------|---------|
| Mac 桌面端 App Store 包 | 商店内购 |
| 桌面端安装包 | 信用卡 / 加密货币 |
| 浏览器插件包 | 信用卡 / 加密货币 |
| iOS 包 | 商店内购 |
| Android Google 商店包 | 商店内购 |
| Android APK 包 | 商店内购 / 信用卡 / 加密货币 |

## 3. 加密货币支付

| 项目 | 需求 |
|-----|------|
| 网络 | Tron、BNB、Ethereum、Arbitrum、Polygon、Base、Solana |
| 资产 | 各网络主币、USDT、USDC |
| App 内支付 | 选定套餐和币种后由 App 创建转账交易 |
| 订单模型 | 每个套餐与支付币种组合创建一个独立订单和独立收款地址 |
| 有效期 | 订单有效期 1 小时 |
| Pending 回访 | 再次打开订阅时提示已支付，用户可开启新订单或继续等待 |
| 超时加速 | 超时 Pending 订单发起转账加速时提示订单超时，并移除转账 |
| 外部钱包 | 跳转 Infini 网页付款 |
| 部分支付 | 仅 Infini 外部网页支付允许部分付款；付款后 App 刷新并展示剩余待支付金额；再次点击外部支付回到原订单继续支付 |
| 套餐切换 | 部分付款后切换套餐进行加密支付时提示已有交易正在处理 |
| 试用 | 加密货币支付不支持 3 天免费试用 |
| 自动续订 | 加密货币支付不支持自动续订 |
| 取消订阅 | 只取消续订 invoice 邮件发送 |
| 支付完成 | App 获取并刷新支付状态，并确认 Prime 权益已更新 |

## 4. 信用卡支付

| 项目 | 需求 |
|-----|------|
| 支付页面 | 跳转外部信用卡支付页面 |
| 金额 | 外部支付页面金额与当前选定套餐一致 |
| 状态 | 支付完成后 App 获取并刷新支付状态，并确认 Prime 权益已更新 |

## 5. 业务规则

- 商店内购、信用卡、加密货币按客户端包限制展示，不展示当前包不支持的支付方式。
- 订单有效期、收款地址和支付币种绑定；超时订单不得继续加速。
- 部分支付仅适用于 Infini 外部网页，必须保留原订单并更新剩余金额，不能创建新订单替代原订单。
- 信用卡和加密货币支付完成后都必须确认 Prime 权益已更新。
- 信用卡试用资格按当前用户 ID 的历史激活状态判断；当前用户 ID 曾通过付费订阅、兑换码或后端赠送激活 Prime 后不得使用 3 天免费试用；删除并重新注册 OneKey ID 生成新的用户 ID 后可重新获得信用卡 trial。
- iOS App Store 和 Android Google Play 的免费试用资格由对应商店独立控制，不受 OneKey ID 历史 Prime 激活状态影响。
- 加密货币支付不进入 3 天免费试用链路，也不创建自动续订。
