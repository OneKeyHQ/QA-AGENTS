## 当前业务口径

1. 封禁账号显示异常 banner 和客服入口，主邀请码/子邀请码不能用于新下单归因或新绑定。
2. 封禁期间停止新增邀请人的 DeFi/Perps/Swap 佣金，不影响既有受邀钱包自身的奖励，不清空既有历史。
3. 解封后提示消失、邀请码可用、新收益恢复计算；按封禁/解封时间划分账期，不重置历史。
4. 2026-11-06 用户确认 Swap 与 Perps 的封禁规则一致；封禁期间停止邀请人新增佣金，保留历史及既有受邀者奖励，解封后恢复新增且不补计停算部分。
5. 被封禁 ID 的当前钱包作为受邀者仍有奖励；福利中心按当前钱包显示，退出 ID 后仍可查看，邀请人佣金不可见。
