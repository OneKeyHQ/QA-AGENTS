## 录入

1. 初始化设置 PIN 后显示“指纹解锁”，说明“使用指纹更快解锁您的设备。您仍可随时使用 PIN。”，按钮为“添加”“暂不”。跳过不新增指纹、不具备指纹解锁能力，不推断“解锁设备”开关关闭。
2. 设备设置→安全→指纹需 PIN 验证。采集从“轻触电源键”“将手指轻放在电源键上。”开始；第一段按指腹、指尖提示采样，中途“调整握持姿势”“继续操作，采集指纹边缘。”，继续采集后完成。不再要求独立固定左/右阶段；每次采样抬起手指后再轻触。
3. 采样图形随有效采样递增；无效采样不增加进度，按对应中文提示调整后继续。按下电源键提示“轻触电源键。不要按压。”。已录入手指显示“此指纹已录入，调整您的手指位置后重试。”，重新开始当前录入，已有指纹保留、不新增重复条目。
4. 超时结果显示“指纹超时”“我们无法检测到您的手指，调整您的手指位置后重试。”；失败结果显示“添加指纹失败”“调整您的手指位置后重试。”。点击“重试”从头采集。关闭后按初始化/设置来源返回，未完成指纹不写入。
5. 完成页显示“指纹已添加”“指纹数据受安全芯片保护。”；勾选动画播放一次并停在末帧，随后显示“完成”。初始化入口继续初始化，设置入口返回指纹列表。

## 管理与解锁

1. 最多两个指纹；未满显示“添加”，满两个时隐藏，移除后恢复。条目点击展示“重命名”“移除”；移除确认显示“移除指纹？”“此指纹将无法再用于解锁您的设备。”及“取消”“移除”。取消保留条目及解锁能力。
2. “解锁设备”默认开启；关闭不删除指纹，锁屏无指纹标识且必须 PIN；重新开启恢复已有指纹解锁。
3. 日常有效指纹解锁响应小于2秒；不匹配提示“指纹不匹配，请重试。”；连续五次失败提示“尝试次数过多，请输入 PIN 解锁。”，只能 PIN 解锁。锁屏与 PIN 输入页计数互通，PIN 解锁后重置。沿用 PIN 错误四次后指纹解锁可重置 PIN 错误计数的既有要求。
4. 重启首次、更改 PIN、指纹管理、关机弹窗取消后锁屏、SeedCard/Keytag 备份、核对助记词及敏感操作二次验证仍需 PIN。日常解锁与敏感授权不能混淆。
5. 重启首次 PIN 解锁后，记录指纹加载画面出现到消失的时间：一个指纹≤2秒，两个≤4秒；随后重新锁屏验证各指纹，不要求跳过开机 PIN。该产品性能指标保留用户选定的仓库基准。
6. 保留录入/移除中断的原子性要求：目标指纹仅可为完整旧态或完整新态，已有其他指纹不受影响。重启先 PIN 解锁，再锁屏检查指纹；断电仅使用已备份的专用设备。
