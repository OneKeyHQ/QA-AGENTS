# Zcash / Monero - 转账 - 软件钱包

## 1. 已确认需求

- Zcash 接入网络，只有 ZEC 主币，无代币；有公开、隐私地址。隐私同步不影响公开地址的现有逻辑。
- 两条链可按时间、区块恢复资产，首次默认今天；同步后显示上次同步时间，可暂停与继续恢复。
- 本轮明确确认：Zcash 恢复下限 2026-07-28、区块 3,428,143；Monero 恢复下限 2014-04-18、区块 1。按具体边界生成用例。
- 本轮明确确认：「记住上次同步时间」按显示上次时间、暂停后从保存进度继续描述。Monero 在未获得所需密钥授权时验证解锁弹出，取消后可再次授权继续，不扩展成每轮同步都必须重复输入密码。
- 隐私地址需开启同步才展示；接收、核对地址均验证提示与开启后展示。
- 隐私账户管理入口：设置 → 钱包 → 隐私管理；钱包选择器 → 隐私同步。
- 两条链最多五个地址同时同步；超出时静默开启新的、关闭一个旧的。只在首页或主币详情页金额处显示当前同步状态，不显示悬浮状态窗。
- 隐私历史为本地记录，隐私地址位置显示「隐私」；Zcash 公开交易可查区块浏览器。
- Monero 支持标准、Cake Wallet 两条路径，两个不同派生地址均执行转账并核对余额及历史归属。路径实例及规则见 `docs/qa/rules/privacy-transfer-rules.md`。
