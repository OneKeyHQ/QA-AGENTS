# Pro2 - 签名手势

> 需求依据：2026-11-07 用户说明；对应 Jira Test：OK-25300。
> 范围：Pro2 设备端设置与交易签名页；不改变交易内容、解析及 App 广播规则。

## 1. 选择签名手势

1. 入口为设备端「设置 → 钱包 → 签名手势」，包含滑动签名、长按签名、点击签名，三选一。
2. 默认选择滑动签名；修改后，后续交易签名页使用所选手势。
3. 滑动签名必须完成滑动才确认，点击或未完成滑动不能确认。
4. 长按签名必须持续按住至确认，过程中显示绿色边框动画并有震动反馈；短按或中途松开不能确认。本批长按反馈用例在震动开启时执行，不规定长按时长。
5. 点击签名通过一次点击确认；同一签名请求不得因重复触摸被重复确认。
6. 关闭通用设置中的震动后，三种手势仍可签名；长按绿色边框动画仍显示，签名过程无震动，重新开启后恢复对应反馈。

## 2. 保留与恢复默认

1. 退出设置、锁屏解锁、重启后保留所选手势，并在交易签名页继续生效。
2. 取消重置不改变手势；完成设备重置并重新初始化后，默认选择滑动签名。
3. 重置场景使用已备份的专用测试设备，安排在其他用例之后；不将重启当成重置。
