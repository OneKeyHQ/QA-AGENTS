## 当前业务口径

1. 邀请人查看各绑定地址、vault 的奖励与质押明细，支持时间/邀请码筛选、导出与月度发放历史。
2. 按实际业绩费的 10% 分别计算邀请人和受邀者奖励；15% 业绩费、扣费后收益 85 时，奖励为 85 / 0.85 × 0.015 = 1.5，不与质押本金混淆。
3. 质押更新明细、赎回保留历史，奖励按小时更新；收益币种与法币价值按当前配置动态核对。
4. 受邀者通过福利页查看当前钱包的 DeFi 奖励，与邀请人 OneKey ID 佣金隔离。
