# Prime - OneKey ID 注册登录

> 模块：Prime
> App 版本：6.7.0
> 日期：2026-10-29
> 测试端：iOS / Android / Desktop / Extension / Web

---

## 1. 需求背景

OneKey ID 是 Prime 会员能力的账号基础。新用户通过 Google / Apple 注册或登录；已有账号可通过邮箱 OTP 登录。完成认证后，当前客户端才能承载 Prime 状态、会员权益与关联功能。

---

## 2. 功能描述

### 2.1 邮箱输入与校验

| 项目 | 说明 |
|-----|------|
| 正确格式 | 正确邮箱格式时允许继续 |
| 错误格式 | 错误格式提示邮箱地址不正确 |
| 邮箱长度 | 支持 6 至 74 字符 |
| 域名支持 | 支持中文域名 |
| 非法格式示例 | `user@domain`、包含 Emoji 的邮箱均视为非法 |

### 2.2 验证码页

| 项目 | 说明 |
|-----|------|
| 邮箱回显 | 验证码页展示输入邮箱，与邮箱输入页保持一致 |
| 倒计时 | 显示 60 秒倒计时 |
| 正确验证码 | 输入后自动提交 |
| 错误验证码 | 提示验证码无效 |
| 超时验证码 | 正确验证码一般在 2 小时内有效 |
| 重发 | 60 秒后可重新发送验证码 |

### 2.3 登录方式与账号绑定

| 项目 | 说明 |
|-----|------|
| Google / Apple | 支持使用 Google 或 Apple 登录；未注册邮箱可通过 Google / Apple 完成 OneKey ID 注册 |
| 邮箱 OTP 注册 | 邮箱 OTP 仅用于已有 OneKey ID 登录，不允许通过邮箱 OTP 注册新账户 |
| 邮箱 OTP 入口 | 邮箱 OTP 登录入口默认折叠，不直接展示 |
| CAPTCHA | 展开邮箱 OTP 登录后，完成 CAPTCHA 人机验证才发送 OTP；加载失败或长时间未完成需显示错误，移动端额外提供网络诊断按钮 |
| 已注册邮箱绑定 | 已注册 OneKey ID 的邮箱使用相同邮箱 Google / Apple 登录时，自动绑定到原 OneKey ID |
| 未绑定邮箱 | 未绑定的邮箱通过 OTP 登录后，可选择 Google 或 Apple 登录方式完成绑定 |
| 多端登录 | 同一邮箱在不同端登录当前不限制 |
| 重复登录 | 退出后支持重复接收验证码并重新登录 |
| 成功后状态 | 登录成功后进入 OneKey ID 体系并承载后续 Prime 状态 |

### 2.5 与 Keyless Wallet 的关联

| 项目 | 说明 |
|-----|------|
| 先登录 Keyless | 自动登录与该钱包关联的 OneKey ID |
| 先登录 OneKey ID | 不自动创建对应 Keyless Wallet，且无法登录其他 Keyless Wallet |
| 删除或主动退出 | 删除 Keyless Wallet，或主动退出 OneKey ID 时，关联的另一方同步退出/删除 |
| 被动退出 | OneKey ID 被其他设备移除等被动退出时，不删除本地 Keyless Wallet |

## 3. 业务规则

| 规则项 | 规则描述 |
|-------|---------|
| 账号基础 | Prime 相关功能以 OneKey ID 登录态为基础 |
| 登录方式 | Google / Apple 支持登录和新账户注册；邮箱 OTP 仅支持已有账户登录 |
| 邮箱 OTP 入口 | 邮箱 OTP 默认折叠；发送 OTP 前必须完成 CAPTCHA |
| CAPTCHA 异常 | CAPTCHA 加载失败或超时显示错误；移动端提供网络诊断入口 |
| 账号绑定 | 已注册邮箱使用同邮箱 Google / Apple 登录时自动绑定原账号；未绑定邮箱 OTP 登录后可选择 Google / Apple 绑定 |
| 邮箱格式校验 | 错误邮箱格式不得进入验证码流程 |
| 长度限制 | 邮箱长度需在 6 至 74 字符范围内 |
| 中文域名 | 中文域名属于有效邮箱类型 |
| 验证码时效 | 验证码页需展示 60 秒倒计时，倒计时结束后允许重发 |
| 自动提交 | 正确验证码输入后自动提交 |
| 多端策略 | 同一邮箱多端登录当前不做限制 |
| 重复进入 | 退出后可重复执行登录流程 |
| Keyless 关联 | Keyless 先登录自动带出关联 OneKey ID；OneKey ID 主动退出/删除与 Keyless 成对处理，被动退出保留 Keyless |

## 4. 已知风险

- 不同邮箱服务商的验证码投递延迟与拦截策略存在差异
- 中文域名邮箱在不同平台输入法与客户端校验上的兼容性待确认
- 验证码有效期与服务端真实过期时间需保持一致

### 4.1 与 OK-25005 基线的差异

| OK-25005 原口径 | 6.7.0 需求口径 |
|----------------|----------------|
| 邮箱 OTP 可用于注册新账户 | 邮箱 OTP 仅用于已有 OneKey ID 登录；新账户使用 Google / Apple 注册 |
| 邮箱登录入口直接展示 | 邮箱 OTP 登录入口默认折叠 |
| 点击继续后直接发送 OTP | 完成 CAPTCHA 后才发送 OTP；加载失败或超时显示错误，移动端提供网络诊断 |
| 仅邮箱登录流程 | 增加 Google / Apple 登录、同邮箱账号绑定和 Keyless 关联边界 |

> 本轮只更新需求和规则，`OK-25005.doc` 对应手动用例暂不改写；后续生成用例时以本节新口径为准。
