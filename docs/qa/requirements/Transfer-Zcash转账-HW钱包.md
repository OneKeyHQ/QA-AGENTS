## 2. 最新确认的验收范围

- 用户后续明确要求简化为四笔主流程：公开 → 公开最小值 `0.00000546 ZEC`、公开 → 隐私 Max、隐私 → 公开 Max、隐私 → 隐私中间值（本批选 `0.01 ZEC`）。「隐私 - 公开中最大值」按其中明确的最大值执行，不展开中间值与最大值两笔。
- 异常仅保留公开 → 隐私、隐私 → 公开两条拒签后重发，金额均选 `0.01 ZEC`；拒签不扣款，重发后到账一次。
- 共 6 条用例，每型号四笔主流程及两笔拒签重发；Pro2 / Neo 各执行本批用例。原先 7 条参数化 / 每型号 20 组方案已由本次确认替代。
- 隐私使用前同步到最新区块，到账后再次同步再核对余额；保留为前置条件，删除独立同步异常、断连和断网恢复用例。
- HW 只直接核对 Zcash、完整收款地址、发送金额和网络费；预期逐项写清发送 / 接收余额变化，不引用重复核对表。
- 用户确认：隐私转账不能查区块浏览器，仅有本地历史；隐私地址位置显示「隐私」。只有公开 → 公开要求区块浏览器查询。
- 仅 ZEC 主币，固定可控制的账户1 ↔ 账户2，发送方为 HW 钱包。Jira 原有用例名称不变。
