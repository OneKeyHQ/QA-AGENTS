### 3.1 登录、账户与空状态

1. 未登录 OneKey ID 可查看当前钱包作为受邀者的奖励；邀请人佣金需要登录 ID，退出后不可见。
2. 桌面宽屏通过 Tab、窄屏及移动端通过切换菜单直接切换两页；页面与选中项一致。
3. 区分无钱包、初始化中、非 EVM 网络但可解析 EVM 奖励地址、完全无可用 EVM 奖励地址、已绑定、未绑定、超期与不支持绑定；绑定完成后刷新当前钱包状态。
4. 非 EVM 网络的选择不等于钱包没有 EVM 奖励地址；可解析时按该地址显示奖励，无法解析时显示不支持状态与切换提示。

### 3.2 金额、活动与交互

1. Perps、Swap、DeFi 的已发放、待发放与汇总按第 3 节口径核对；未估值代币不当作美元数量相加。
2. 福利中心统计地址不可手改，与邀请人 ID 接收地址分别展示；发放说明按当前币种/网络及账期显示。
3. 用户确认原第 7 章全部细节，包括详情弹窗、加载/刷新失败、活动轮播、无奖励与停用产品、移动端分享、地址显隐及主题/语言适配。

### 3.3 邀请码自定义与大小写

1. 自定义邀请码仅允许 3 至 15 位字母数字，且每个邀请码只能自定义一次；之后代码输入框禁用，备注仍可编辑，备注修改不重置次数。
2. 邀请码不区分大小写；ABC123、abc123、aBc123 指向同一邀请码与邀请关系，绑定与邀请链接均适用。
3. 已存在邀请码的大小写变体不能作为另一独立邀请码保存；大小写变化不绕过唯一性与一次修改限制。
