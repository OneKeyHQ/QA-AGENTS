## 订单簿

1. 按当前市场和价格档位展示公开买卖盘口。核对价格、数量、两侧排序和累计量，有价差字段时按同一快照核对。有效的一侧随新盘口刷新，空侧显示占位，数据恢复后显示最新档位。
2. 按市场保存档位选择。切换档位或市场时隔离行情数据，保留布局。Android 全页行情切档后仍可滚动到横向订单簿。旧版回归见 [OK-67026](https://onekeyhq.atlassian.net/browse/OK-67026)、[OK-59102](https://onekeyhq.atlassian.net/browse/OK-59102)。
3. 交易页盘口提供双边、仅买、仅卖三种样式，默认双边。桌面顶部三个图标直选，移动交易页底部图标按双边 → 仅买 → 仅卖 → 双边循环。单边展开该侧更多档位，当前档位和买卖比例保持一致，价格区域持续显示。
4. 桌面行情顶部及竖向盘口、移动交易页盘口及全页行情页头展示当前市场的最新成交价。买方成交为绿，卖方成交为红，无有效成交时显示「--」。盘口的永续标记价、现货参考价独立显示，随当前市场切换。
5. 点击实时档位可填入限价表单，空档、缓存和过时盘口仅供查看。移动交易页也可点击最新成交价填入限价，需同时有未满 30 秒的 WS 成交和当前有效盘口。仅有 HTTP 快照、断线或任一数据过期时保持表单。BBO 及布局重置沿用各自专项用例。

## 市场最近成交

1. Desktop / Web 从市场面板切换「订单簿」和「最近交易」。iOS / Android 从全页 K 线下方切换。移动端交易页的紧凑盘口及现货盘口沿用原入口。
2. 「最近交易」展示当前永续市场的公开成交。合并首屏快照和实时推送，同一时间与成交 ID 的记录合并，按时间和成交 ID 依次倒序，保留最新 50 条。切换市场隔离旧请求及推送。
3. 每行核对成交价格、数量、买卖方向和时间。价格可补末尾零，保留实际成交精度。Desktop / Web 直接显示 Tab 和含当前资产单位的数量列头，原生端可点数量列头查看完整标题。 [列头展示 OK-67832](https://onekeyhq.atlassian.net/browse/OK-67832)
4. 有效成交哈希的图标打开 Hyperliquid 浏览器对应的成交路径，零哈希按原值传入。无有效哈希时隐藏图标，TWAP 或清算说明属于浏览器落地结果。
5. 区分首屏加载、暂无数据、失败和离线。无数据的错误或离线状态及重试按钮居中，等待重试时按钮显示加载并禁用。已有记录时，WS 断线或 HTTP 回补失败保留当前市场的有效记录，重连后继续更新和去重。 [重试样式 OK-67830](https://onekeyhq.atlassian.net/browse/OK-67830)
6. Desktop / Web 切回订单簿保留最近交易的 50 条消费需求 30 秒，超时释放，返回后恢复需求并回补。同市场最新价可继续使用共享 WS 连接。移动端全页行情内切换时保留最近交易需求，离页或退后台释放，返回后恢复。
