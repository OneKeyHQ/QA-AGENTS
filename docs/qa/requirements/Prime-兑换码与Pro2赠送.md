## 1. 兑换码生成

| 项目 | 需求 |
|-----|------|
| 后台配置 | 支持配置 Prime 权益时长（天）和兑换码数量 |
| 有效期 | 兑换码有效期 1 年 |
| 一次性 | 每个兑换码只能成功使用一次 |

## 2. 普通兑换码使用

| 场景 | 需求 |
|-----|------|
| 付费订阅用户 | 已有付费订阅时不可兑换，需提示不可兑换 |
| 赠送/兑换 Prime 用户 | 允许继续兑换，Prime 时长在当前剩余时长基础上累计 |
| 已使用兑换码 | 提示兑换码已使用 |
| 过期兑换码 | 提示兑换码已过期 |
| 成功兑换 | 当前登录 OneKey ID 获得配置的 Prime 时长，并刷新会员状态 |

## 3. Pro2 赠送会员

| 项目 | 需求 |
|-----|------|
| 入口 | Pro2 onboarding 或设备管理中提供 Prime 兑换入口 |
| 资格展示 | 已兑换设备或非 Pro2 设备不展示兑换入口 |
| 流程 | 检查 OneKey ID 登录状态 → 验证设备 → 领取资格 |
| 切换账号 | 进入流程后允许切换当前登录 OneKey ID；领取结果归属领取时的当前账号 |
| 设备验证 | 设备验证通过后才能领取资格；QA 设备验证失败时不得发放资格 |
| 领取结果 | 可直接展示并复制兑换码；点击领取可直接兑换到当前登录 OneKey ID |
| 兑换规则 | 领取后仍遵循普通兑换码的一次性、过期、付费订阅不可兑换和时长累加规则 |

## 4. 业务规则

- 兑换资格由设备状态决定，不能通过隐藏入口或切换到非 Pro2 设备绕过资格判断。
- 设备验证失败时不得生成可用的兑换结果。
- 兑换码展示、复制和直接领取属于同一资格流程，不能重复领取同一设备资格。
- 账号切换后必须重新确认当前 OneKey ID，不能把前一账号的待领取结果提交给后一账号。
