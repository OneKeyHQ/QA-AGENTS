> **测试端**：全端（iOS / Android / Extension / Desktop / Web）

## 📋 需求背景

### 需求简介
- 模糊搜索：多语言 Ticker（中/英/日等），规则服务端可配置；**中文搜索与界面语言无关**，非中文环境下也可用中文关键词搜到。
- Token 选择器分类 Tab：可后台自定义新增、配置代币归属哪个分类；C 端按配置展示。
- 中文标签：代币列表/行情顶展示中文标签，**仅当界面语言为中文时显示**；多语言标签可后台自定义配置。

### 影响范围
Token 选择器（搜索、分类 tab、列表展示）；后台可配置分类、代币归属、多语言标签；C 端与配置一致。基础搜索覆盖全端；搜索弹层快捷键及桌面高度对齐覆盖 Desktop / Extension / Web，iOS / Android 保留触屏回归。

## 🎯 功能描述

### 功能点 1：模糊搜索（多语言 Ticker）

- 模糊匹配 Ticker 或别名，多语言（中/英/日等）及规则由服务端配置。
- 中文搜索不依赖界面语言：英文/日文等环境下输入中文关键词仍可搜到对应代币。
- 空输入、无结果、超长/特殊字符：有默认列表或空状态提示，按服务端或前端规则处理。

### 功能点 2：Token 选择器版块

- 版块列表由服务端配置（如贵金属、股票、Pre-IPO），以标签/分组展示；点击版块筛选该版块下代币。
- 未配置或下架的版块不展示。
- 无关键词时按子分类展示；有关键词时在当前资产类型内搜索，不被热门、股票等永续子分类二次限制。清空关键词后恢复当前子分类；自选仅搜索收藏，现货仅搜索现货。

### 功能点 3：中文标签（仅中文环境）

- 在列表项、行情顶等位置展示**中文标签**（代币中文 Ticker/名称，若有）。
- **仅当界面语言为中文时显示**；非中文环境不显示；无中文数据不显示。

### 功能点 4：后台配置

- **分类 Tab**：可自定义新增、编辑、排序或下架分类 tab（即 Token 选择器内的版块）；配置后 C 端展示与配置一致。
- **代币归属**：可配置每个代币归属到哪个分类（一个代币可属多分类或仅属单分类，以产品规则为准）；C 端点击某分类 tab 仅展示该分类下已配置的代币。
- **多语言标签**：可自定义配置代币在多语言下的展示标签（如中文名、英文名、日文名等）；C 端按当前界面语言展示对应语言的标签，且搜索可命中各语言配置。

---

### 功能点 5：搜索弹层快捷键与选中

- 通过现有交易对入口打开后，使用 ↑↓ 导航、←→ 切换主 Tab、Enter 选择资产、⌘S（macOS）/ Ctrl+S（Windows / Linux）切换当前资产收藏，Esc 关闭；不新增全局打开快捷键。
- 有结果的当前分类 / 搜索结果默认仅选中第一项，可直接 Enter；鼠标与键盘共享一个操作目标，始终只有一项高亮。
- 主 Tab 按自选 / 永续合约 / 现货顺序双向循环；空输入及输入内容后均可左右切换，关键词保持不变，光标位于开头 / 中间 / 结尾均可触发。
- 无结果或加载尚未完成时，不允许选择或收藏旧结果；有结果后默认首项。输入法候选阶段不触发选币、切 Tab 或收藏，带修饰键的文字编辑不误触快捷操作。
- 自选从顶部连续取消时自动选中下一项；从底部连续取消时自动选中上一项，支持连续取消。移除最后一项后无失效高亮，展示对应空状态。
- 可使用的快捷键样式突出；不可用提示与按键行为一致，不把已知缺陷中的禁用样式或无默认选中当预期。

### 功能点 6：切换 Tab 高度一致

- 相同窗口与缩放下，自选 / 永续合约 / 现货的搜索输入框、整个弹层及列表可视区域高度分别一致；永续的二级分类不使整体增高，底部快捷键栏不跳动。
- 单条 / 多条 / 空结果 / 推荐 / 加载状态保持该高度约束；小窗口在共同约束内滚动展示，不以写死像素验收。
