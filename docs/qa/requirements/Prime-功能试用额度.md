## 1. 需求背景

本功能是 Prime 专属功能的按月额度试用，与商店/信用卡订阅的 3 天会员试用不同。试用功能、额度和开关由后端 Dashboard 配置。

## 2. 支持功能与额度

| 功能 | 额度口径 | 前端展示 |
|-----|---------|---------|
| 批量复制地址 | 按使用次数统计 | 展示剩余额度 |
| 批量发送 | 按使用次数统计 | 展示剩余额度 |
| 批量取消授权 | 按使用次数统计 | 展示剩余额度 |
| 地址风险检查 | 按使用次数统计 | 展示剩余额度 |
| DApp 翻译 | 按翻译消耗 token 统计 | 不展示额度 |

## 3. 试用资格与入口

| 场景 | 需求 |
|-----|------|
| 未登录 + 支持且已开启试用 | 点击功能时展示登录弹窗 |
| 未登录 + 不支持或未开启试用 | 点击功能时展示 Prime 购买页面 |
| 已登录 + 试用额度充足 | 进入对应功能并按额度规则扣减 |
| 额度不足 | 提示额度不足和下次重置时间，并跳转 Prime 购买页面 |
| 后端配置 | 支持功能开关和具体额度由后端 Dashboard 配置 |

## 4. 额度计算与回退

| 规则项 | 需求 |
|-------|------|
| 失败操作 | 功能执行失败不计入使用额度 |
| 部分成功 | 部分成功按实际成功结果计入额度 |
| 月度重置 | 试用额度每月重置 |
| 发起锁定 | 批量复制地址、批量发送、批量取消授权发起后先锁定一次额度 |
| 完成扣减 | 成功完成或部分完成后按实际成功结果扣减额度 |
| 退出/失败 | 功能退出或失败时回退锁定额度 |
| 异常回退 | 非正常退出时，批量复制地址 10 分钟后自动回退；批量发送和批量取消授权 30 分钟后自动回退 |
| 跨客户端可见 | 当账号只剩最后一次额度且该额度处于锁定状态时，其他登录同一账号的客户端展示解锁时间 |

## 5. 业务规则

- 功能试用与 3 天会员试用独立计算，不能把功能试用额度折算为会员天数。
- 额度扣减以实际成功结果为准；失败、取消和超时锁定回退不能形成永久扣减。
- DApp 翻译按 token 消耗统计，额度不在前端展示，但额度不足时仍需按统一购买引导处理。
