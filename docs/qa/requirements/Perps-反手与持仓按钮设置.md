## 2. 已确认需求

### 2.1 反手

- 持仓区增加反手，目标是同数量反向持仓。
- 先弹窗确认，展示操作、数量、价格与预估强平价。
- 提交一笔相反方向的市价单，订单数量 = 当前绝对持仓数量 × 2，关闭只减仓。
- 原多仓 Q：卖出 2Q；原空仓 Q：买入 2Q。全部成交且无其他持仓变更后，目标为反向 Q。

### 2.2 按钮设置

- 移动端增加操作按钮菜单，可选择直接显示的按钮，例如平仓、止盈止损、反手。
- 未勾选的操作直接隐藏；更改自动保存。
- 持仓按钮设置仅限 iOS / Android；不将 Web / 插件窄屏作为移动端配置场景。

## 3. 交易保护与配置规则

以下行为已于 2026-10-27 由用户确认，对应用例见 §4–5：

- 始终确认，不受跳过普通下单确认影响；确认展示当前与反手后持仓、市价单 2Q、参考价及预估强平价。
- 启用交易与异步行情准备前后校验账户 / 市场 / 数量 / 方向；变更后拒绝旧快照。
- 复用 $10 最低金额及最大可交易数量；覆盖最小金额以下 / 等于 / 以上以及可交易上限小于 / 等于 / 大于两倍仓位，数量精度必须保留精确两倍，保留原杠杆及保证金模式。
- 重复确认防重、提交中阻止关闭、失败恢复、行情重试、无强平估算占位、Agent 签名、现货隔离与同名市场隔离。受理后关闭确认，不等待实际成交；一笔订单可能有多条成交，按累计数量核对。
- 部分成交不自动补单，不主动撤原挂单或止盈止损，不附加新止盈止损；使用既有 8% 市价滑点。
- 移动端默认四个操作（加仓 / 反手 / 止盈止损 / 平仓）全部开启，可以全部隐藏；同机跨账户保留、跨设备不同步。
- 移动端布局入口、加仓开关、K 线设置隔离及隐藏止盈止损后已有订单的显示。

## 4. 平台范围

持仓按钮设置仅在 iOS / Android 执行，不包含桌面端或 Web / 插件窄屏配置，也不设计窄屏配置后切回桌面的显隐场景。反手功能本身保留多端覆盖。

## 5. 接口与三线影响

- 建议接口 / 服务层检查一笔反向市价单、两倍数量、`reduceOnly=false`、`coin` / `expectedAccountAddress` 作用域、无 TP/SL、无额外撤单、数量精度 / 最低金额 / 最大数量及异步仓位变化。
- UI 自动化后续对照用例章节生成。当前未找到直接对应反手或按钮显隐的 UI / API 用例，无需改现有图表、收藏、搜索、投资组合脚本。
- 本次为手动用例设计与文档维护，未执行钱包交易或断言产品通过。
