# Account - 备份与恢复能力

> 模块：Account  
> 来源：基于 `docs/qa/rules/account-rules.md` 补充整理  
> App 版本：6.7.0
> 日期：2026-04-14  
> 测试端：Desktop / Extension / iOS / Android / Web

---

## 1. 需求背景

Account 模块除手动助记词备份外，还支持云备份、OneKey Lite、OneKey KeyTag 和数据传输等多种备份与恢复方式。不同能力在数据范围、权限验证、媒介限制和恢复结果上存在明显差异，需要统一整理。

---

## 2. 功能描述

### 2.1 云备份与导入

| 项目 | 说明 |
|-----|------|
| 移动端备份密码保存 | 移动端支持保存单个云备份的备份密码，用于后续下载该备份 |
| 备份范围 | 展示当前 App 内所有 HD 钱包和私钥 / 公钥 / 观察账户；不包含Keyless Wallet |
| 账号来源 | Google Drive 需登录或选择 Google 账号；iCloud 使用系统账号 |
| 首次备份 | 必须设置备份密码，两次输入一致且长度不少于 6 位 |
| 再次备份 | 必须验证已设置的备份密码 |
| 首次下载验证 | 备份和第一次下载时，验证备份密码后还需完成生物识别验证，并保存该备份的密码 |
| 再次下载验证 | 再次下载同一备份时无需重新输入备份密码，仅需完成生物识别验证 |
| 生物识别失败/取消 | 下载云备份时，生物识别失败或用户取消后，仍需支持改用备份密码继续下载 |
| 密码保存范围 | 保存的备份密码只对应单个备份；不同备份即使使用相同密码，也必须分别完成生物识别验证并保存 |
| 密码生命周期 | App reset 后保留已保存的备份密码；卸载 App 后清除已保存的备份密码 |
| 导入列表 | 新版格式数据列表展示备份时间和钱包账户数量；旧格式数据导入口位于新版列表下方 |
| 新版导入 | 校验备份密码后下载所选钱包，再设置当前 App 密码 |
| 旧版导入 | 支持从旧数据入口导入旧格式备份 |
| 删除与重置 | 删除备份前需要二次确认并验证 App 密码；重置备份密码仅影响新备份 |

### 2.2 OneKey Lite

| 项目 | 说明 |
|-----|------|
| NFC 权限 | 首次进入备份、导入、修改 PIN、重置时申请 NFC 权限 |
| 备份能力 | 支持将 12 / 15 / 18 / 21 / 24 位助记词钱包备份到空卡 |
| PIN 规则 | 需设置并二次确认 6 位 PIN |
| PIN 验证 | 覆盖备份、导入、修改 PIN 前都需先验证 Lite PIN |
| PIN 错误 | 错误次数递减，累计 10 次错误后卡片重置 |
| 重置确认 | 需先输入 `reset` 才可发起重置 |
| 识别异常 | 贴卡取消、移开卡片、空卡、不同卡片等都显示连接或卡片错误提示 |

### 2.3 OneKey KeyTag

| 项目 | 说明 |
|-----|------|
| 入口 | 设置页显示购买、备份、导入入口 |
| 导入方式 | KeyTag 导入改为点阵图输入；导入时单词不正确显示 toast 提示 |
| 点阵图版式 | 点阵图参考实物卡片，每面显示 12 个单词；超过 12 个单词时需手动修改单词数量并翻面 |
| 备份方式 | 支持选择现有软件钱包备份，也支持手动输入助记词生成 dotmap |
| 权限 | 选择现有钱包备份前需完成密码或生物识别验证 |
| 未备份钱包验证 | 未备份钱包进行 KeyTag 备份时，要求输入并验证点阵图；已备份钱包不要求该验证 |
| 点位操作 | 点击点阵图位置标记打孔位置，再次点击同一位置取消标记 |
| 提交校验 | 提交点阵图时，存在未输入行则切换到对应未输入位置并提示；备份验证时单词不匹配显示提示 |
| 失败提示 | 备份验证多次失败时提示用户核对点阵图；只有改变输入内容后才可再次触发该提示，未修改输入的重复失败不触发 |
| 教程 | 右上角帮助展示备份教程，勾选“我已备份”后才可关闭 |
| 核对 | dotmap 点位和行数需与助记词一一对应 |

### 2.4 数据传输

| 项目 | 说明 |
|-----|------|
| 建立连接 | 默认选中二维码 tab，二维码与配对码一致 |
| 配对码 | 支持粘贴、扫码录入，默认暗文显示，可切换明文 |
| 配对校验 | 不可连接自己的配对码；无效码、超时、一端退出、第三端抢占都需要中断并提示 |
| 自定义服务器 | 支持域名、`http/https`、IP+端口，自动补全协议并记录历史 |
| 数据范围 | 支持导出和导入软件钱包、私钥钱包、观察钱包；Keyless Wallet不参与 |
| 数据限制 | HD 钱包 LN / ADA 数据不导入 |

## 3. 业务规则

| 规则项 | 规则描述 |
|-------|---------|
| 备份范围边界 | 云备份不包含Keyless Wallet |
| 密码隔离 | 云备份密码与当前 App 密码可不同；重置备份密码仅影响新备份 |
| 移动端密码缓存 | 移动端仅缓存单个备份的备份密码；首次备份/首次下载在备份密码验证后必须完成生物识别；同一备份再次下载仅需生物识别 |
| 下载验证回退 | 云备份下载的生物识别失败或取消后，必须保留备份密码验证入口，允许使用备份密码继续下载 |
| 缓存隔离与生命周期 | 不同备份分别保存验证结果，即使密码相同也不能复用；App reset 保留缓存，卸载 App 清除缓存 |
| 版本兼容 | 云备份导入同时兼容新版与旧版数据 |
| Lite 安全门槛 | Lite 覆盖、导入、修改 PIN 都必须先验证 Lite PIN |
| KeyTag 校验 | KeyTag 的导入规则、风险确认和 dotmap 核对需保持一致 |
| 数据传输限制 | Keyless Wallet不参与数据传输，HD 钱包 LN / ADA 不导入 |
| 异常可解释 | NFC、卡片识别、配对码、超时与连接中断都需显示可解释提示 |

## 4. 已知风险

- 云备份新版与旧版数据入口并存，容易出现列表展示、导入密码和结果归属不一致。
- 移动端备份密码缓存涉及单备份隔离以及 App reset / 卸载两种生命周期，需分别验证。
- Lite 的 NFC、PIN、空卡、识别异常组合较多，端间实现差异明显。
- KeyTag 点阵图与实物卡片的单面 12 词、翻面和点位状态容易出现展示与校验不一致。
- KeyTag 未输入行、单词不匹配、错误单词和重复失败提示存在不同触发条件。
- 数据传输涉及双端状态与服务器配置，超时、中断和第三端抢占需要重点验证。
