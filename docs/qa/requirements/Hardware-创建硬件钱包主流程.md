# Hardware - 创建硬件钱包主流程

> App 版本：
> 测试端：Desktop / Extension / iOS / Android / Web
> 变更记录：
> - 2026-07-31 首版；同时记录 Pro2 未激活设备新流程（「设置您的设备」三步引导）

## 1. 已激活设备连接创建钱包

1. 点击「连接硬件钱包」，选择「蓝牙」/「USB」标签，展示已检测到的设备列表
2. 选择设备（设备处于锁定状态）→ 提示输入 PIN 码，唤起设备响应
3. 输入正确 PIN 码 → 进入设备验证状态，唤起设备响应
4. 设备上点击「确认」→ 设备验证通过，验证页面内容显示正确
5. 点击「继续」→ 进入创建钱包 loading 页面，创建钱包成功
6. 默认创建账户 1：BTC 四个路径地址 / ETH BIP44 地址 / Solana BIP44 地址 / Tron 地址
7. 网络选择其他链时创建钱包，会将当前链与默认地址一起创建
8. 切换账户或切换链不会自动创建，需手动点击创建
9. 地址正确性基线：同一套助记词导入 bip39 工具或 OKX，所有链地址一致

## 2. 未激活设备激活引导（Mini / Classic / Classic 1S / Touch / Pro）

1. 选择未激活设备 → 唤起设备响应，进入设备验真状态
2. 设备上点击「确认」→ 验真通过，验真页面内容显示正确
3. 点击「继续」→ 弹出激活引导页面，显示「创建钱包」与「恢复钱包」按钮
4. 点击「创建钱包」→ 进入创建钱包说明页面，不同设备对应不同说明页面
5. 点击「恢复钱包」→ 进入恢复钱包说明页面，不同设备对应不同说明页面
6. 点击「获取帮助」→ 跳转官网帮助中心

## 3. Pro2 未激活设备新流程（设置您的设备）

Pro2 未激活设备不走上面的激活引导页，改为 App 侧「设置您的设备」三步引导页（时间线样式），设备端操作驱动 App 侧步骤推进：

1. **完善基础设置**：说明「请选择语言，然后为您的设备命名。」，底部设备图标提示「请在设备上继续」；在设备上完成后该步骤打绿色对勾，自动推进到下一步
2. **创建 PIN 码**：在设备上创建 PIN，完成后打绿色对勾
3. **设置钱包**：说明「创建新钱包，或恢复已有钱包：」；列出两个选项——「创建新钱包：在设备上生成新的助记词。」「恢复钱包：从助记词或 SeedCard 恢复。」；底部提示「请在设备上选择一个选项」
4. App 会判断当前入口选择的是「创建钱包」还是「导入（恢复）钱包」，「设置钱包」步骤提示不同的文案（文案以设计稿为准）
