## 观察账户候选问题

实际选择 `watching` 账户后，真实派生状态为 `accountNotSupport=true`、`canTrade=false`，但完整委托列表仍出现可点击的追单入口，并打开追单预览。当前未启用 agent、拒绝条款的本地样本在确认时被实际 ensure 流程阻止，精确验证零改单、零启用、零密码确认、零资金入口，并恢复按钮任务锁。

## 离线边界与执行分组

真实组件、hook、校验与服务方法在隔离环境执行；网络响应、配置发布结果、atom/storage、portal、布局和剪贴板为明确的本地边界。搜索列表行以其计算出的身份渲染为本地 host，未检查实际行像素/数值格式；保证金 mode 确认使用本地 exchange 响应，必须等真实 feed 方法写回才断言模式变化；充值重开验证真实 hook 新生命周期和旧内存缓存，不等同真实 App 磁盘重启。

真实后台配置发布、TF 界面/布局、系统能力和磁盘恢复留给实机。执行时按 [执行分组与账户前置](./Perps-执行分组与账户前置.md) 分批索取目标：只读/输入/预览组提供观察地址或钱包账户；真实订单组另行提供钱包账户和交易参数；保证金设置/启用交易与资金操作分别排期，不混入只读组，也不自动创建订单补样本。

本批只补 UI 源码隔离断言和审核映射，手动用例的业务预期保持，API 自动化无需同步改写。源码候选没有按现状回写手动预期；知识已沉淀 K-399～K-402。
