# Perps 原生图表固定样本 v1

本数据仅用于独立测试配置中的数值与几何核对。测试参数由本次补例选择，不是产品默认参数；不得导入真实账户或把虚构市场用于交易。

## 执行准备

1. 使用隔离测试环境，以固定行情替换历史加载及实时推送的输入；市场标识为 QA-NATIVE-USD，周期 1m、UTC，完整输入为 indicators.json 的 mixed.bars。先清空同市场缓存，禁止混入实时行情或额外前置历史。
2. 短历史和零成交量分别替换为 short.bars、zero-volume.bars；每组完整重载，从数组首根重新预热，不能只把后续几根追加到上一组。图表数据窗口的首末时间、条数和 OHLCV 必须先与样本一致。
3. 原生行情接入点为 TradingViewNative/data/useTradingViewNativeKLine.ts 的数据边界；网络替身或测试适配器必须同时覆盖历史与订阅。样本校验不直接调用产品计算器作为预期。普通 TF 包若未接入受控行情，该批数值样本标记“环境未就绪”，不得以实盘近似值报告通过。
4. 绘图输入按 drawings.json 的 anchors 顺序取点，指定点数的工具取前 N 点，自由路径沿 A→H。固定屏幕投影仅用于独立几何验算，实机使用当前可见坐标轴换算，不调整用户窗口，不把任意画布像素当成固定价格。
5. 故障批次使用可撤销的存储／提交替身。保存：在 chartLocalStorage.ts 调用 appStorage.setItem 调用边界的边界挂起／拒绝 Promise，不绕过队列；读取：在 appStorage.getItem 边界返回失败。订单：在提交输送到交易所之前拒绝请求，计数器确认出站提交为 0，读取订单接口保持可用。每次 finally 恢复替身、配置并读回。

## 数值口径与容差

- 独立生成器 generate.py 只使用 Python 标准库，不读取产品计算器。SMA 为完整窗口平均；EMA 首个值取首个完整窗口的 SMA，再以 2/(n+1) 平滑；RSI、DMI 使用首窗均值初始化的 Wilder 平滑 1/n。缺失历史保留 null，不补零。
- BOLL 使用总体标准差；MACD 柱为 DIF−DEA，不乘 2；OBV 首值为 0，按后续收盘方向加减成交量。SAR 首个方向由头两根收盘确定，次根以首根最低／最高价起算，随后使用极值、加速因子和前两根极值夹取。
- StochRSI 为 RSI 的窗口高低归一化至 0–100，再做 K/D 简单平均；MFI 按典型价方向加权成交量，完整方向窗口后出值，负流为零时为 100。TRIX 采用 ln(close) 的三次 EMA 差乘 10000；EMV 为中点位移×价差×divisor/量，再做 SMA。
- WR=100×(close−最高价)/(最高价−最低价)；ROC=100×(close/前n根close−1)；MTM=close−前n根close；CCI 使用典型价的平均绝对偏差；DMI 的 ADXR 比较相距 n−1 根的 ADX。所选非退化样本避开零分母，零量组 EMV 为 null、MFI 按流量规则计算。
- 原始值误差≤1e−8+1e−8×|期望值|；UI 将独立值按当前显示精度舍入后比较，允许半个末位显示单位的舍入差。坐标字段按编辑精度比较；未磁吸的可见锚点允许≤2 CSS 像素指针误差，缩放后应换算回该时刻的当前坐标。时间按 UTC 和对应 K 线起点对齐。
- 复算：python3 docs/qa/test-data/perps/native-chart-v1/generate.py --check。更改公式或输入后必须重新评审预期，禁止根据被测输出自动改写冻结值。

## 绘图数值与操作判据

[drawings.json](drawings.json) 包含 A–H 锚点、90 项工具的输入映射及数值判据。所有永久工具均核对保存／重进后的控制点、工具类型和对象数量；自由笔迹核对采样轨迹，不能把自动生成的辅助线当成多次创建。复杂曲线按其可编辑控制点和适用比例逐项比对，不用“画出了图形”代替坐标判据。

| 项目 | 固定输入与预期 |
| --- | --- |
| A→B 线段／射线／信息线／测量 | A=00:00/100，B=00:02/120；间隔120秒、相隔2个1m周期、价差20、涨幅20%；中点00:01/110；射线只沿A→B延伸，延长线双向延伸 |
| 水平／垂直／十字／箭头 | 在A落点：水平价100、垂直时间00:00；定向箭头方向与所选工具一致；双点箭头终点B |
| 通道 | A→B斜率每分钟10，C=00:04/110，平行线相对基线在C处偏移−30；两边斜率相同 |
| 矩形／椭圆／三角形 | A、B边界00:00–00:02、100–120，中心00:01/110；三角形顶点A/B/C，跨度240秒，价域100–120 |
| 斐波那契回撤 | A=100、B=120，0在B、1在A；0/.236/.382/.5/.618/.786/1对应120/115.28/112.36/110/107.64/104.28/100；反向后两个端点互换 |
| 扩展／时间比例 | A→B价差20、C=110；扩展0/.618/1/1.618/2.618对应110/122.36/130/142.36/162.36；时间0/1/2/3/5/8倍间隔对应A后0/2/4/6/10/16分钟 |
| 江恩箱／圆弧等几何 | 箱体半分位为00:01/110；圆以A为圆心B为圆周点时，在样本投影半径sqrt(80²+120²)；其他比例线按选中的倍率和同一投影换算，不混用价格单位和屏幕角度 |
| 形态／波浪／路径 | 按映射顺序落A–H中前N点，逐点读回时间和价格；标签顺序见drawings.json，折线依次连相邻输入点，不能倒置或错用前一工具的点 |
| 多头／空头 | 入场110、目标120／100、止损100／120；获利与亏损均10、比值1；对象增加且无订单产生 |
| 文字／图标 | A处输入“原生 Chart 123”及第二行“第二行 !@#”；重开按同锚点、原字符及真实换行核对；图标核对当前选中图案和A坐标 |
| 层级 | 初始自底向上红A／绿B／蓝C；B前移后红A／蓝C／绿B，B从初始后移后绿B／红A／蓝C；核对重叠处最上层与选中目标 |

价格分布、锚定VWAP等依赖行情的工具同时使用同一20根输入；A至B含首尾3根，成交量合计330，锚定VWAP在B为101.2727272727；其他区间按典型价×量累计和／量累计和独立复算。角度和半径按实机当前轴映射独立换算，不能跨缩放直接套固定像素。
