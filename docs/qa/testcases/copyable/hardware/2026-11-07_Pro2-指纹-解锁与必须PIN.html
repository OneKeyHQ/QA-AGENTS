Pro2 - 指纹解锁与必须 PIN 安全场景

前置条件

1. Pro2 专用测试设备已初始化并已备份，至少录入 1 个指纹；日常解锁场景先完成重启后的首次 PIN 解锁，并开启“解锁设备”。

2. 准备非注册手指（如不同人手指或另一根未录入手指）用于无效指纹场景

3. 设备 PIN 已知；额外准备一组错误 PIN（用于解锁错误场景）

4. 准备一台已初始化但未录入指纹的 Pro2，用于验证锁屏页无指纹标识场景

5. USB 数据线 + 已开启 USB 锁的配置场景（用于 USB 插拔兼容场景）

1. 锁屏后指纹解锁入口
