Pro2 - 指纹录入流程与异常恢复

前置条件

1. 准备已备份的专用 Pro2 测试设备，分别具备未初始化、已初始化零个指纹、已初始化一个指纹的状态；设备语言设为简体中文。

2. PIN 已知，并准备一组错误 PIN；准备已录入手指及不同的未录入手指。

3. 日常解锁验证先完成开机首次 PIN 解锁，并开启“解锁设备”；初始化场景依步骤单独准备。

4. 采样异常使用可清洁、无损的污渍及不同覆盖、移动方式；断电仅在专用测试设备执行。

3. 新版分段采集

操作步骤

P1

轻触引导与内圈采集

1. 进入录入页，观察引导

2. 轻放手指，每次采样后抬起，再调整位置轻触

调整握持与边缘采集

2. 看到调整握持引导后换姿势，按提示采集边缘

1. 显示“调整握持姿势”“继续操作，采集指纹边缘。”

2. 继续采集后进入完成页，不要求固定左、右两个独立阶段

采集与完成动画

1. 录入过程中观察采样反馈

2. 采集完成后等待完成页动画

2. 完成页勾选动画播放一次并停在末帧，随后显示“完成”按钮

4. 采样异常与恢复

优先级

场景

操作步骤

预期结果

❗️❗️P0❗️❗️

重复录入已有指纹

1. 已录入一个指纹，点击“添加”

2. 使用已录入手指采集，出现重复提示后换未录入手指完成

1. 显示“此指纹已录入，调整您的手指位置后重试。”

2. 本次采集重新开始，不新增重复条目

3. 新手指完成后共两条；原指纹仍能解锁

P1

移动过快或采样质量不足

1. 采集时快速划过或移动手指，触发无效采样提示

2. 抬起并重新放置手指

1. 显示“抬起手指，换个位置重试。”

2. 无效采样不增加进度，重新放置后可继续采集

P1

覆盖传感器不足

1. 仅以少量指腹接触传感器，触发覆盖不足提示

2. 增加覆盖面积后再次轻触

1. 显示“让手指覆盖更多传感器区域。”

2. 无效采样不增加进度，调整后可继续采集

P1

同一区域反复采集

1. 反复用相同位置采样，触发调整位置提示

2. 更换手指接触位置继续

1. 显示“抬起手指，换个位置重试。”，不把此情况描述为已录入另一条指纹

2. 无效采样不增加进度，调整后可继续采集

P1

录入时按下电源键

1. 录入过程中按下电源键

2. 松开后轻触，继续采集

1. 显示“轻触电源键。不要按压。”

2. 已完成采样保留，后续轻触可继续采集

P1

传感器脏污

1. 传感器存在污渍并触发清洁提示

2. 清洁、擦干后重新采集

1. 显示“清洁电源键后重试。”

2. 无效采样不增加进度，清洁后可继续采集

P1

采集时手指抖动

1. 轻触后移动手指，触发保持静止提示

2. 调整为静止轻触

1. 显示“保持手指静止。”

2. 无效采样不增加进度，静止后可继续采集

P1

过度施压导致覆盖提示

1. 采集时过度施压但不按下电源键，触发覆盖提示

2. 减轻力度并调整接触范围

1. 显示“让手指覆盖更多传感器区域。”

2. 不新增指纹或增加无效采样进度；调整后可继续

5. 超时与失败

优先级

场景

操作步骤

预期结果

P1

录入超时后重试

1. 录入一部分后长时间不触摸，直到显示超时结果页

2. 点击“重试”后重新采集

1. 显示“指纹超时”“我们无法检测到您的手指，调整您的手指位置后重试。”及“重试”

2. 重新从录入起点采集，不续接原进度

3. 完成前列表不新增条目

P1

连续无效采样后重试

1. 连续触发无效采样，直到显示录入失败结果页

2. 点击“重试”，按提示重新采集

1. 显示“添加指纹失败”“调整您的手指位置后重试。”及“重试”

2. 重新从录入起点采集，不续接原进度

3. 完成后仅新增一条指纹

P1

关闭超时或失败结果页

1. 分别从初始化与设置入口触发超时或失败

2. 点击结果页关闭按钮

1. 初始化入口继续初始化，设置入口返回指纹列表

2. 未完成采集不写入指纹列表，原有指纹保留

6. 错误 PIN 与采集中退出

优先级

场景

操作步骤

预期结果

❗️❗️P0❗️❗️

进入指纹设置输入错误 PIN

1. 设备设置→安全→指纹

2. 在验证页输入一组错误 PIN

1. 显示“PIN 错误”及剩余次数提示

2. 停留在 PIN 验证页，不进入指纹管理

❗️❗️P0❗️❗️

内圈或外圈采集中退出

1. 已有一个指纹，分别在新增指纹的内圈、调整握持后外圈采集中关闭退出

2. 返回列表后锁屏，分别使用未完成手指和原手指

1. 列表保留原指纹，不新增未完成条目

2. 未完成手指不能解锁；原手指可解锁

7. 录入中断与重启加载

优先级

场景

操作步骤

预期结果

❗️❗️P0❗️❗️

录入期间断电恢复

1. 分别在零个指纹录入第一个、已有一个录入第二个时，在采集或保存过程中断电

2. 重启后先用 PIN 解锁，查看列表；再次锁屏核对每条指纹

1. 新指纹要么未写入，要么完整写入且能解锁，不出现有条目但无法识别的中间态

2. 录入第二个时，原指纹仍可解锁

3. 重启首次解锁必须 PIN

P1

一个或两个指纹重启加载

1. 分别准备一个、两个已录入指纹，重启并使用 PIN 完成首次解锁

2. 记录指纹加载画面出现到消失的时间；再次锁屏并逐个验证指纹

1. 一个指纹加载时间≤2秒；两个指纹≤4秒

2. 进入主屏幕后再次锁屏，各已录入指纹均可解锁

3. 不以开机后直接指纹解锁替代首次 PIN 验证
