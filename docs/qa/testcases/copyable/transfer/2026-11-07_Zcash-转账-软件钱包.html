Zcash - 转账 - 软件钱包

前置条件与测试数据

1. 使用支持 Zcash 的受测端及有余额（含网络费）的 HD 钱包账户1、账户2，准备双方公开、隐私地址；交易用例实际签名、广播并核对到账。

2. 金额：最小值 0.00000546 ZEC，中间值 0.01 ZEC（小于 Max）；每笔 Max 前重新准备发送余额，核对确认页金额及实际网络费。

3. 恢复下限：2026-07-28 / 区块 3,428,143；准备下限之后已有入账的账户及无同步记录账户；隐私转账前先同步到最新区块，到账后再同步对账。

4. 五个名额用例分别准备六个不同的 Zcash 隐私地址和六个不同的 Monero 地址，供跨链及两链各自的同链场景使用；执行前记录启用状态，执行后恢复。

两个隐私账户管理入口

1. 从「设置 → 钱包 → 隐私管理」进入 Zcash 账户管理，记录目标账户的同步状态

2. 从「钱包选择器 → 隐私同步」选择同一钱包及 Zcash 网络，查看同一账户

2. 按提示开启隐私同步后，再查看并复制隐私地址

1. 开启前提示先开启隐私地址同步，不展示可复制的隐私地址

2. 开启后显示本账户隐私地址；复制内容与展示地址一致

1. 使用无同步记录的账户打开开启隐私同步弹窗，查看默认日期

2. 取消开启后再次进入

1. 首次恢复日期为设备当地今天

2. 取消后账户未开启同步；再次进入仍默认今天

P1

按日期恢复 · 日期边界（长周期）

1. 在恢复日期中检查 2026-07-28 前一天、2026-07-28、今天及明天

2. 选择 2026-07-28，开启同步并等待同步至最新区块

1. 可选日期为 2026-07-28 至今天；更早日期和未来日期不可提交

2. 从所选日期恢复；测试数据中该日期及以后已有的 ZEC 入账显示在本地余额、历史中

2. 输入 3,428,143，开启同步并等待同步至最新区块

1. 无效高度不能开启同步，并显示输入校验提示

2. 3,428,143 可提交；从该高度恢复测试数据中的 ZEC 入账，余额与本地历史对应

P1

暂停后继续

1. 同步过程中记录进度并暂停，等待当前区块处理结束后观察

2. 继续同步，等待到最新区块

1. 暂停后进度停止推进，账户显示暂停状态

2. 继续后从已保存进度推进，无需重填恢复起点；已有余额和历史不重复累计

P1

上次同步时间持久化

1. 完成一次同步，记录页面显示的上次同步时间

2. 退出页面并重启 App，再进入同一账户；继续同步后查看时间

1. 重进页面仍显示该账户上次同步时间

2. 再次同步后时间更新；已保存同步进度未因页面重进而清空

P1

同步状态展示位置

1. 保持账户同步未完成，分别查看首页及主币详情页金额区域

2. 切换到其他页面，再暂停、继续并完成同步

1. 首页或主币详情页金额处显示对应账户的当前同步状态

2. 状态随暂停、继续及完成更新；各页面不出现悬浮同步状态窗

P1

1. 本账户 ZEC 余额增加 0.01；本地历史显示一次入账

2. 本地历史隐私地址位置显示「隐私」；不依赖区块浏览器查询隐私入账
