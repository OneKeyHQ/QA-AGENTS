# Market - 图表设置

> 生成时间：2026-08-04  
> 需求文档：`docs/qa/requirements/Market-图表设置.md`  
> 规则文档：`docs/qa/rules/market-rules.md` §5  
> 测试端：Desktop（截图基线）；Extension / Web 抽测同等能力。  
> 测试数据：选择有 K 线、价格、深度和财经日历数据的活跃 Token；另准备无财经日历数据的 Token。

## 测试范围说明

覆盖图表设置弹窗的导航、K 线颜色、坐标、财经日历、版面、确认/取消/关闭/重置、配置应用与持久化。图表数据准确性、周期、指标及缩放平移仍由 [Market-图表](2026-03-26_Market-图表.md) 覆盖。

## 1. 入口与弹窗行为

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 1. 已进入有 K 线的 Token 详情页<br>2. 图表加载完成 | 点击图表工具栏的「图表设置」入口 | 显示「图表设置」弹窗；包含 K 线、坐标、事件、版面导航，以及重置、取消、确认和关闭入口 |
| P1 | 图表设置弹窗已打开 | 依次选择 K 线、坐标、事件、版面 | 当前页签有选中态；内容区仅展示所选页签的配置项；切换不丢失本次未确认修改 |
| P1 | 图表设置弹窗已打开 | 点击关闭图标，重新打开弹窗 | 弹窗关闭；未确认修改不应用到图表 |
| ❗️❗️P0❗️❗️ | 图表设置弹窗已打开并修改任一配置 | 点击取消，重新打开弹窗 | 图表保持修改前状态；弹窗回显修改前的已确认配置 |

## 2. K 线颜色设置

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| P1 | 1. K 线页已打开<br>2. 图表有涨、跌两类 K 线 | 切换「涨跌颜色」选项并确认 | 配色预览与图表中上涨、下跌 K 线颜色同步切换；涨跌语义与所选配色一致 |
| P1 | K 线页已打开 | 分别取消主体、边框、影线开关并确认 | 被关闭部分不再渲染；其他仍启用部分保持显示 |
| P1 | K 线页已打开 | 分别启用主体、边框、影线并为涨、跌状态选择不同颜色后确认 | 各部分按对应涨跌颜色渲染；未被修改的 K 线样式不发生串色 |
| P2 | 已在 K 线页完成多项颜色和开关修改 | 反复切换页签后返回 K 线页 | 配置控件回显本次选择；颜色预览、勾选状态与图表当前预览一致 |

## 3. 坐标与最新价格设置

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 坐标页已打开 | 分别关闭倒计时、深度显示、价格涨跌幅并确认 | 图表价格坐标区域不再显示对应字段；未关闭字段保持显示 |
| P1 | 已关闭上述任一坐标字段 | 重新启用该字段并确认 | 对应字段恢复显示，数值与当前图表数据一致 |
| ❗️❗️P0❗️❗️ | 1. 图表存在最新价格<br>2. 坐标页已打开 | 关闭「最新价格」并确认 | 最新价格标签和价格线不再显示 |
| P1 | 「最新价格」已启用 | 切换最新价格线型和颜色并确认 | 图表最新价格线的线型、颜色与设置预览一致；最新价格数值不变 |

## 4. 财经日历事件

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 1. 当前 Token/时间范围存在未来财经事件<br>2. 事件页已打开 | 启用「显示未来事件」并确认 | 图表显示未来事件标记；标记位置与事件时间对应 |
| P1 | 未来事件已显示 | 关闭「显示未来事件」并确认 | 图表不再显示未来事件标记 |
| P1 | 1. 当前 Token/时间范围存在过往财经事件<br>2. 事件页已打开 | 启用「显示过往事件」并确认 | 图表显示过往事件标记；标记位置与历史事件时间对应 |
| P2 | 当前 Token 无财经日历数据 | 分别开关未来事件和过往事件并确认 | 图表保持可用；不显示伪造事件标记或错误提示 |

## 5. 版面与图表交互

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 版面页已打开 | 启用「点击启用交互」并确认，在图表区域点击 | 图表按产品定义响应点击交互；不影响其他图表操作 |
| P1 | 「点击启用交互」已启用 | 关闭该选项并确认，在图表区域点击 | 点击不再触发该交互；图表不出现异常状态 |
| P1 | 版面页已打开 | 修改背景样式和颜色并确认 | 图表背景样式、颜色与设置预览一致；K 线、文字和坐标保持可辨识 |
| P1 | 版面页已打开 | 修改网格线方向和颜色并确认 | 图表仅显示所选方向的网格线；颜色与预览一致 |
| P1 | 十字线已启用 | 修改十字线线型和颜色并确认，在图表中移动光标 | 十字线跟随光标；线型、颜色与设置一致；OHLC 等悬停信息仍可读取 |
| P1 | 十字线已启用 | 关闭十字线并确认，在图表中移动光标 | 不显示十字线；图表不闪烁或卡死 |

## 6. 确认、重置与持久化

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 已修改至少一项 K 线、坐标、事件或版面配置 | 点击确认，关闭并重新打开设置弹窗 | 图表应用全部已确认修改；各配置项回显已确认值 |
| ❗️❗️P0❗️❗️ | 已修改至少一项配置 | 点击重置后点击确认 | 所有配置恢复产品定义的默认值；图表同步恢复默认样式和显示项 |
| P1 | 已确认自定义配置 | 切换至另一 Token 后返回原 Token | 配置保留范围与产品定义一致；若为全局配置，两 Token 显示一致 |
| P1 | 已确认自定义配置 | 重启应用后进入同一 Token 详情页 | 配置保留范围与产品定义一致；不回退为随机状态 |
| P2 | 已确认自定义配置 | 在 Extension / Web 重复打开图表设置并抽测核心配置 | 与 Desktop 的配置项、确认/取消/重置行为一致；平台特有缺失项有产品说明 |
