# 返佣 - DeFi 奖励

> 更新日期：2026-11-05
> 测试端：iOS / Android / Extension / Desktop / Web
> 规则文档：`docs/qa/rules/referral-rules.md`
> 需求文档：`docs/qa/requirements/Referral-DeFi奖励.md`
> 需求来源：Jira Test OK-24414；2026-11-05 用户确认返佣差异清单并授权补充、review 与同步。

## 前置条件

1. 准备当前测试支持的 vault 与对应收益币种，有奖励/无奖励、一个/多个 vault、已登录/未登录 ID 状态。
2. 准备邀请人及已绑定受邀钱包的测试账户，记录质押量、收益金额、业绩费、奖励与快照数据；不要使用固定 APY 推算实际到账。
3. 质押、赎回、快照和发放数据由测试环境准备；本任务仅编写用例，不执行真实资产操作。

## 1. 进入 DeFi 推荐与邀请奖励

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 已登录 OneKey ID，名下有 DeFi 返佣 | 从邀请奖励进入 DeFi 产品详情 | 显示当前 ID 的所有受邀 vault 奖励合计与明细入口 |
| P1 | Earn 分享入口，未登录 / 已登录 | 点击 Earn 的推荐奖励图标 | 未登录显示邀请介绍与登录入口；已登录显示当前邀请码、查看奖励与了解更多入口 |
| P1 | 无奖励 | 打开 DeFi 邀请奖励详情 | 显示无奖励状态；待发放和总计为零 |
| P1 | 首次进入月度奖励提示 | 关闭提示后退出再进入；另以未关闭状态再次进入 | 已关闭时不再显示；未关闭时仍显示按月发放说明 |

## 2. 核对邀请地址与 vault 明细

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 一个受邀钱包有多个地址和多个 vault 奖励 | 展开该钱包地址奖励明细 | 显示脱敏地址、vault、质押量、奖励币种和金额；地址汇总等于其各 vault 奖励之和 |
| ❗️❗️P0❗️❗️ | 两个邀请码均有 DeFi 奖励 | 查看全部邀请码的奖励合计 | 合计包含两个码的奖励；同一已绑定地址不重复计数 |
| P1 | 多个地址奖励不同 | 查看列表默认顺序 | 地址按奖励金额从高到低排列 |
| P1 | 已绑定钱包新增同助记词下的地址并产生收益 | 待测试奖励更新后展开明细 | 该地址显示在绑定钱包的奖励明细，归属原邀请人 |
| P1 | 同一地址存在历史与本期奖励 | 展开明细并切换时间范围 | 历史奖励仍存在；所选时间内的金额与当前范围内记录一致 |
| P1 | 汇总以 USD 与当前法币显示 | 切换显示法币并对照当前汇率 | 币种数量不变；法币金额按当前汇率换算并按显示精度舍入 |

## 3. 奖励计算与质押赎回联动

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 测试记录的扣费后收益为 85 USDC，业绩费率 15% | 待奖励更新后分别查看邀请人及受邀者明细 | 两侧奖励分别为 85 / 0.85 × 0.015 = 1.5 USDC；不将质押本金乘以返佣率 |
| ❗️❗️P0❗️❗️ | 邀请人为铜 / 银 / 金 / 钻石，同一收益与业绩费 | 核对各等级的 DeFi 奖励 | 每侧奖励为业绩费的 10%，不随硬件/合约/Swap 等级变化 |
| P1 | USDC / USDT / DAI / WETH / WBTC / cbBTC 中当前支持的收益资产 | 对各收益币种核对返佣明细 | 各币种按实际业绩费基数计算；法币合计使用各币种当前估值，不直接相加代币数量 |
| P1 | 新质押 / 已有质押地址追加质押 | 在测试环境完成对应状态后查看明细 | 新地址新增一条归属记录；已有地址更新质押量和 vault 明细，不重复新增绑定关系 |
| P1 | 部分赎回 / 全部赎回 | 奖励数据更新后查看同一地址 | 质押量随赎回减少；历史奖励保留；全部赎回的仓位不再新增该仓位收益 |
| P1 | 收益按小时更新 | 记录更新前金额，等待一个奖励更新周期后刷新 | 明细显示最新测试收益及对应奖励，不重复累加同一小时记录 |
| P1 | 钱包绑定前已有质押，绑定后继续产生新收益 | 按绑定时间分段核对明细 | 仅计绑定后符合条件的收益；不把绑定前历史收益补作本期邀请奖励 |

## 4. 快照、发放与奖励历史

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 已设置邀请人接收地址，有待发放奖励 | 核对月初快照、发放后汇总与发放历史 | 快照记录与当期奖励一致；发放后已发放累加对应金额，待发放按新周期累计；历史显示对应币种、金额和时间 |
| P1 | 未设置邀请人接收地址 | 等待测试结算周期并刷新 | 不显示已发放记录；未发放奖励保留到后续周期 |
| P1 | 有多个 vault 的月度记录 | 打开发放历史并点击交易哈希 | 月度记录包含对应 vault 奖励；交易哈希跳转至对应网络浏览器 |
| P1 | 重复进入历史页 / 刷新详情 | 比较发放前后的累计金额 | 同一笔发放不重复计入累计；总计等于已发放加待发放 |

## 5. 筛选、导出与异常恢复

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| P1 | 有跨时间、跨邀请码的数据 | 切换时间与邀请码后导出 | 统计与列表仅显示所选范围；导出记录、币种和金额与当前筛选范围一致 |
| P1 | 筛选后无记录 | 切换到无数据范围后清除筛选 | 先显示空列表与零统计；清除后显示原有记录 |
| P1 | 首次加载失败 / 已有数据后刷新失败 | 断网后恢复网络并重试 | 显示失败提示与重试入口；恢复后显示当前用户数据，不显示其他账户记录 |
| P2 | 桌面宽屏 / 移动窄屏 | 展开多个 vault 并滚动列表 | 金额与数据一致；字段可读，展开/收起与筛选入口可点击 |

## 6. 受邀者查看奖励与福利页联动

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 当前钱包有 DeFi 受邀奖励 | 从福利页打开 DeFi 奖励详情 | 显示当前钱包奖励、vault 明细及发放历史；金额与福利页分项一致 |
| P1 | Earn 投资详情中有返佣 / 无返佣的地址 | 打开对应投资详情与奖励入口 | 有返佣地址显示推荐奖励字段和明细入口；无返佣地址不显示该字段 |
| P1 | 钱包 A / B 的 vault 和奖励不同 | 在福利页切换账户后打开 DeFi 详情 | 显示当前地址的 vault、金额与历史；不混入上个账户数据 |
| P1 | DeFi 加载失败，其他产品已加载 | 在福利页点击 DeFi 重试 | DeFi 显示失败与重试入口；其他产品数据仍可见，汇总不展示缺项合计 |
