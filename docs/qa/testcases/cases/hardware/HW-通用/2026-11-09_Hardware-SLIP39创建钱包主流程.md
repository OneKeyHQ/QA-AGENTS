# Hardware - SLIP39创建钱包主流程

> 规则文档：docs/qa/rules/hardware-rules.md（§19）
> 需求文档：docs/qa/requirements/Hardware-通用专项用例补齐.md
> 测试端：设备端 / Desktop（App及离线参考核对）
> Jira 对应：OK-54830；仅同步description，保留未授权修改的字段。

## 前置条件

1. 适用设备：Pro，沿用原Jira明确支持范围；其他型号不据蓝牙支持自动加入SLIP39范围。
2. 准备未初始化测试Pro，使用测试PIN，指纹可稍后设置；本轮创建份额仅在受控测试环境保管，不写入仓库或日志。
3. 单份默认20词；多份参数分别为2份阈值2、8份阈值8、16份阈值2，每组独立初始化并记录所有份额。
4. 准备标准/隐藏钱包的独立离线参考与测试密语onekey；核对工具入口：https://hardware-example.onekeytest.com/expo-example/api-payload。

## 1. 用例内容

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 单份20词创建 | 设置语言与PIN，稍后设置指纹，在钱包类型选择单份SLIP39，完成备份、随机单词核对及引导 | 显示20个单词；核对通过后进入钱包就绪及首页，App可添加本次钱包 |
| ❗️❗️P0❗️❗️ | 多份三组参数 | 分别按2/2、8/8、16/2参数创建多份钱包，依次备份并核对全部生成份额 | 分别生成2、8、16份，每份20词，阈值分别为2、8、2；未完成的份额不被误标为已核对 |
| P1 | 份额数量与阈值联动 | 分别将份额数设为2、8、16，查看可选阈值后确认对应参数 | 份额2仅可选阈值2；份额8可选2至8；份额16可选2至16，不可选超出范围值 |
| P1 | 标准与隐藏钱包派生 | 对各组本轮生成份额，使用达到阈值的份额建立独立参考，分别核对空密语及onekey密语地址 | 设备、App及离线参考在同一网络、路径、密语下地址一致，单份与多份均有记录 |
| P1 | 创建中取消后重新进入 | 在备份确认前取消，再重新进入并完整创建、备份及核对 | 不将未完成备份标记为已验证；本轮完整创建的钱包可连接并核对地址 |
