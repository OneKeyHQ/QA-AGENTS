# Hardware - 蓝牙配对-性能测试

> 规则文档：docs/qa/rules/hardware-rules.md（§19）
> 需求文档：docs/qa/requirements/Hardware-通用专项用例补齐.md
> 测试端：iOS / Android（蓝牙）
> Jira 对应：OK-24614；仅同步description，保留未授权修改的字段。

## 前置条件

1. 适用设备：Classic / Classic 1S / Classic Pure（Pure）/ Touch / Pro / Pro2 / Neo；Mini 不支持蓝牙，不执行蓝牙部分。
2. 准备iOS与Android手机各一台，记录设备原有配对；每轮从无本次连接的状态开始。
3. 连续取消/重新配对至少5轮；双手机测试轮流交换先发起方，保证可观察的请求先后。

## 1. 用例内容

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| P1 | 连续取消与重配 | 连续5轮发起、取消、重新配对，每轮最终明确完成连接并请求地址 | 每轮均可再次配对并取到目标地址；无旧弹窗、重复设备或持续搜索卡住 |
| P1 | 两手机同时请求 | 先由手机A发起配对，再由B立即发起；完成A配对后核对双方状态，再交换先后执行 | 先发起方可完成本轮配对，同时仅一台手机获得有效连接；另一台不误显示已连接 |
| P1 | 连接释放后另一手机接管 | 断开已连接手机，再由另一手机发起配对并请求地址 | 旧手机显示断开，新手机完成连接并取得目标地址，无两台同时占用的残留状态 |
