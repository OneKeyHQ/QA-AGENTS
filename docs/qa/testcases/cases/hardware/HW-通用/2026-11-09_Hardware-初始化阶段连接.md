# Hardware - 初始化阶段连接

> 规则文档：docs/qa/rules/hardware-rules.md（§19）
> 需求文档：docs/qa/requirements/Hardware-通用专项用例补齐.md
> 测试端：iOS / Android / Desktop / Extension / Web（按本份适用通道及第三方钱包范围执行）
> Jira 对应：OK-24651；仅同步description，保留未授权修改的字段。

## 前置条件

1. 适用设备：Mini / Classic / Classic 1S / Classic Pure（Pure）/ Touch / Pro / Pro2 / Neo，按各型号已支持的功能及受测端连接方式执行。
2. 创建、导入各执行一轮，在教程阶段暂停；USB与蓝牙按设备和App端已支持的通道组合执行。
3. Pro2使用三步设备设置引导；Pro/Touch与旧型号教程差异分开核对，不套用同一完成时机。

## 1. 用例内容

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | Pro与Touch停留教程 | 在Pro、Touch的创建或导入教程未结束时，从App连接并添加设备钱包；完成教程至首页后重试 | 教程未完成时不能提前完成App钱包添加；设备进入首页后可完成连接及账户添加 |
| P1 | 旧型号教程阶段连接 | 在Mini、Classic、Classic 1S、Classic Pure的教程阶段由App连接并添加设备钱包 | App可完成钱包添加，设备退出教程进入首页；Mini仅通过USB执行 |
| P1 | Pro2设置阶段连接 | 连接尚未完成设置的Pro2，依次完成基础设置、PIN及创建/恢复钱包 | App显示设备设置引导，按设备进度推进；完成设置后才完成App钱包添加 |
| P1 | 连接取消后再次进入 | 在初始化阶段取消App连接，保持设备当前阶段，再重新连接并完成剩余步骤 | 可再次进入与设备进度一致的流程，无重复账户或遗留连接弹窗 |
