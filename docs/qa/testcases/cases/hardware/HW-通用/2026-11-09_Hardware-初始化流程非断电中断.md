# Hardware - 初始化流程非断电中断

> 规则文档：docs/qa/rules/hardware-rules.md（§19）
> 需求文档：docs/qa/requirements/Hardware-通用专项用例补齐.md
> 测试端：iOS / Android / Desktop / Extension / Web（按本份适用通道及第三方钱包范围执行）
> Jira 对应：OK-24442；仅同步description，保留未授权修改的字段。

## 前置条件

1. 适用设备：Mini / Classic / Classic 1S / Classic Pure（Pure）/ Touch / Pro / Pro2 / Neo，按各型号已支持的功能及受测端连接方式执行。
2. 使用可重置的专用设备，分别在创建、导入流程的语言、PIN、助记词和教程阶段执行；各轮重新准备未初始化状态。
3. USB插拔组保证电量充足且设备不掉电；低电组使用可控低电量设备，NFC组仅适用Pro。

## 1. 用例内容

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| P1 | 等待至低电自动关机 | 在各初始化阶段停止操作，等待设备低电自行关机，再充电开机 | 本次流程终止，重新开机页面完整；可重新进入初始化，未完成的钱包不被误标为已备份 |
| P1 | 按键取消后重新进入 | 在各阶段使用该型号提供的取消或电源按键退出，再重新进入创建或导入 | 取消后退出当前操作，重新进入可继续填写，无半屏、残留按下状态或闪退 |
| P1 | USB插拔不造成掉电 | 在各阶段插拔USB，保持设备由电池供电并继续操作 | USB插拔不清空未激活流程中的已输入内容，不跳过确认步骤；后续可完成初始化 |
| P1 | Pro初始化中贴NFC卡 | 在Pro各初始化阶段靠近测试NFC卡，移开后继续原流程 | 无未经确认的钱包恢复或数据覆盖；初始化界面可继续操作，无闪退或持续遮挡 |
| P1 | 中断后重新初始化并对账 | 取消或低电重启后重新完成创建/导入，用App连接并核对账户地址 | 仅产生本轮完成的钱包；导入地址与参考一致，PIN及备份状态与实际完成步骤一致 |
