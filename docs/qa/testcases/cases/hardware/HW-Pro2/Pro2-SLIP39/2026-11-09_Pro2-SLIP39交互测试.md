# Pro2 - slip39 交互测试

> 规则文档：docs/qa/rules/hardware-rules.md
> 需求文档：docs/qa/requirements/Hardware-Pro2专项用例补齐.md
> 测试端：Pro2 设备端；按本份前置条件配合 iOS / Android / Desktop / Extension / Web。
> Jira 对应：OK-54834；同步字段：description。

## 前置条件

1. Pro2 已激活，使用已备份的专用测试钱包；重置、断电或输错 PIN 场景使用独立设备状态。
2. 准备 20/33 词 SLIP39 测试钱包，日常回归用 20 词；标准及密语钱包有测试余额，密语使用受控测试值。
3. USB/蓝牙按端支持执行；二维码钱包、参考地址及关联 PIN 已准备；消息工具：https://metamask.github.io/test-dapp/、https://dapp-example.onekeytest.com/solana。

## 1. 钱包交互

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 标准/隐藏钱包转账 | 通过 USB/蓝牙连接，MetaMask 在 Polygon、OneKey 在 Octa 发起测试转账；隐藏钱包使用同一密语重复受支持转账 | 设备显示本次账户、网络、收款地址及金额；广播后交易记录、到账及费用与签名一致，标准/隐藏账户不混用 |
| P1 | 设备收款地址 | 在标准钱包、相同密语钱包分别打开设备收款页 | 完整地址分别与对应 SLIP39 独立参考一致 |
| P1 | 二维码连接与消息签名 | 导出钱包二维码并连接；MetaMask test-dapp 执行 Personal Sign/Typed Data V4，OneKey SOL 工具执行 signMessage/solSignOffchainMessage | 扫码可连接目标账户，各消息签名由目标地址验签通过；不把另一个钱包的地址用于验签 |
| P1 | 关联 PIN 切换 | 开启 Passphrase 并绑定测试 PIN，分别以主 PIN、关联 PIN 解锁查看设备收款地址 | 主 PIN 显示标准钱包地址，关联 PIN 显示对应密语地址；完整地址各与独立参考一致 |
