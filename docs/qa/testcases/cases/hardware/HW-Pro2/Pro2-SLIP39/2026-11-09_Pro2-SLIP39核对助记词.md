# Pro2 - Slip39 核对助记词

> 规则文档：docs/qa/rules/hardware-rules.md
> 需求文档：docs/qa/requirements/Hardware-Pro2专项用例补齐.md
> 测试端：Pro2 设备端；按本份前置条件配合 iOS / Android / Desktop / Extension / Web。
> Jira 对应：OK-54835；同步字段：description。

## 前置条件

1. Pro2 已激活，使用已备份的专用测试钱包；重置、断电或输错 PIN 场景使用独立设备状态。
2. 准备本机 20 词多份额钱包及 33 词单份额钱包，原备份与新生成备份分别有参考身份；按实际阈值提供份额。

## 1. 核对与错误修正

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 20 词多份/33 词单份核对 | 设置→钱包→核对助记词，输入主 PIN，选择对应词数并逐份输入至阈值；再用此前同钱包的有效备份核对 | 本机份额达到阈值后显示核对一致；每份输入后的剩余数与阈值一致；同钱包此前有效备份也可核对 |
| P1 | 错误 PIN/无效/非本机份额 | 分别输入错误主 PIN、无效份额、非本机有效份额，再在列表修正为本机有效份额 | 错误 PIN 扣减剩余次数；无效份额与不匹配分别提示；修正后可继续核对，不改变种子 |
| P1 | 第二份重复或无效 | 已接受一份后，再输入相同份额或含错误单词的第二份，最后补齐不同有效份额 | 重复时提示输入不同份额，无效时提示有效份额，两种均不增加已接受数量；补齐阈值后显示核对一致 |
