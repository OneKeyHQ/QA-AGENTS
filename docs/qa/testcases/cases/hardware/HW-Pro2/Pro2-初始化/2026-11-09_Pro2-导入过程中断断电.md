# Pro2 - 导入过程中断/断电

> 规则文档：docs/qa/rules/hardware-rules.md
> 需求文档：docs/qa/requirements/Hardware-Pro2专项用例补齐.md
> 测试端：Pro2 设备端；按本份前置条件配合 iOS / Android / Desktop / Extension / Web。
> Jira 对应：OK-54255；同步字段：description。

## 前置条件

1. 使用可重置的专用 Pro2，设备未激活；每个参数开始前恢复该状态，测试种子均无真实资产。
2. 使用受控 TEST_ONLY 向量及独立参考地址，记录词数、路径和索引；完整助记词仅从受控测试数据源获取。
3. 各断电点独立执行；分别覆盖重启和真实断电，不能仅拔掉由电池供电设备的 USB 线。

## 1. 导入提交边界

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| P1 | PIN 后与指纹阶段 | 分别在 PIN 完成后的指纹页、指纹已录入页重启/断电再开机 | 设备仍未激活，可重新进入初始化；没有可使用的半导入钱包 |
| P1 | 最后一个单词提交临界 | 分别在最后一个词尚未提交时、提交后但尚未显示钱包已就绪时断电；再开机重新完成导入并核对地址 | 显示钱包已就绪之前断电，开机后仍未激活；重新导入后完整地址与选定向量一致，不混入中断输入 |
| P1 | 钱包已就绪及后续阶段 | 分别在钱包已就绪页、后续备份引导、首页重启/断电再开机 | 设备已激活，必须先用 PIN 解锁；App 获取的地址与本轮导入向量一致 |
