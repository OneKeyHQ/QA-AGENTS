## 前置条件

1. Pro2 已激活，使用已备份的专用测试钱包；重置、断电或输错 PIN 场景使用独立设备状态。
2. PIN 详情、指纹、安全密钥及安全检查各复用独立用例；本份只覆盖入口联动、随机键盘及 USB 锁。

## 1. 安全设置联动

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | USB 锁开启/关闭 | 开启 USB 锁，插入及拔出 USB 后解锁；关闭后重复插拔 | 开启时每次插拔设备锁定，关闭时插拔不因 USB 锁而锁定；设备供电变化不绕过主 PIN |
| P1 | 随机/固定 PIN 键盘 | 分别切换随机与固定排列，多次打开 PIN 输入页，输入相同已知 PIN | 随机模式各轮排列变化且每个数字仅一个；固定模式排列固定，两种模式均按实际所点数字校验 |
| P1 | 安全功能入口与返回 | 分别进入更改 PIN、指纹、安全检查、安全密钥，再返回；更改 PIN 的提示及输入页各取消一次 | 各入口跳转至对应页面并可返回安全页；取消不修改原 PIN，详细功能沿用各独立用例 |
