# Pro2 - 键盘防误触

> 规则文档：docs/qa/rules/hardware-rules.md
> 需求文档：docs/qa/requirements/Hardware-Pro2专项用例补齐.md
> 测试端：Pro2 设备端；按本份前置条件配合 iOS / Android / Desktop / Extension / Web。
> Jira 对应：OK-55004；同步字段：description。

## 前置条件

1. Pro2 已激活，使用已备份的专用测试钱包；重置、断电或输错 PIN 场景使用独立设备状态。
2. PIN/Passphrase/助记词输入页各执行；准备可清空的测试内容，PIN 错误门槛详测复用 PIN 错误次数用例。

## 1. 输入与长按

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 滑动修正按键 | 分别在 PIN 数字、Passphrase 字母/数字/符号及助记词字母键盘，手指按住字符键不离屏，平移到另一字符后松开 | 按住的字母/数字/符号字符显示放大提示；仅最终选中字符输入一次，页面不被误识别为返回手势 |
| P1 | 按键提示排除项 | 分别按空格、大小写切换、数字/符号切换、删除及提交 | 这些功能键不显示字母放大提示，各自仅执行一次所点功能 |
| P1 | 长按删除与退出 | 在 PIN/Passphrase/Word 页输入多字符，长按删除直至清空再松手；数字页再次点击已变为退出的键 | 字符逐个删除直到为空，PIN 圆点全部消失；长按清空不连带退出，松手后再次点击退出才离开页面 |
| P1 | 非手指触碰 | 在 PIN 页用指甲盖/数据线轻触，随后用指腹点击 | 非有效触碰不录入 PIN，指腹点击可录入；不额外提交或返回 |
