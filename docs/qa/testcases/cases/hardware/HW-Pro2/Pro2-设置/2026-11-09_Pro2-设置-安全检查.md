# Pro2 - 设置 - 安全检查

> 规则文档：docs/qa/rules/hardware-rules.md
> 需求文档：docs/qa/requirements/Hardware-Pro2专项用例补齐.md
> 测试端：Pro2 设备端；按本份前置条件配合 iOS / Android / Desktop / Extension / Web。
> Jira 对应：OK-54996；同步字段：description。

## 前置条件

1. Pro2 已激活，使用已备份的专用测试钱包；重置、断电或输错 PIN 场景使用独立设备状态。
2. App 连接设备，Sepolia 测试账户有 tETH 及费用；准备可控接收地址。

## 1. 开关与测试网交易

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 默认开启拦截测试网交易 | 确认安全检查默认开启，App 发起 Sepolia tETH 转账 | 设备提示需要关闭安全检查；未明确关闭前不返回本次签名，交易未广播 |
| P1 | 禁用取消/确认 | 在安全检查页点击关闭先取消，再次进入风险提示并滑动禁用 | 取消后仍开启；滑动后关闭，设置页底部显示黄色风险警告 |
| P1 | 关闭后签名及重启恢复 | 关闭状态重新发起 tETH 转账并核对确认、广播；随后重启查看开关 | 本次不再要求关闭安全检查，到账与确认金额一致；重启后安全检查恢复开启 |
