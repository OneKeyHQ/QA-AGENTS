# Pro2 - 设备 - 关于设备

> 规则文档：docs/qa/rules/hardware-rules.md
> 需求文档：docs/qa/requirements/Hardware-Pro2专项用例补齐.md
> 测试端：Pro2 设备端；按本份前置条件配合 iOS / Android / Desktop / Extension / Web。
> Jira 对应：OK-54997；同步字段：description。

## 前置条件

1. Pro2 已激活，使用已备份的专用测试钱包；重置、断电或输错 PIN 场景使用独立设备状态。
2. 记录受测系统、蓝牙、Bootloader 版本与构建号；Boot 重置子项使用已备份专用设备，其他检查后再执行。

## 1. 固件与 Boot 信息

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 关于设备与认证 | 进入关于设备，核对系统/蓝牙/Bootloader 版本，打开设备认证再返回 | 版本与本轮已安装版本一致，无缺失字段；认证信息可查看，返回关于设备页 |
| P1 | 手动进入 Boot 与设备信息 | 插电后按 Pro2 入口从右上向左下反复滑动进入 Boot，打开 Device Info 并返回 | 进入 Boot 菜单；构建号等信息与目标 Boot 一致，返回上级菜单 |
| P1 | Boot 重启取消/确认 | 分别进入 Reboot Device 后取消、再进入后确认重启 | 取消返回 Boot 上页；确认后设备重启进入固件流程 |
| P1 | Boot 重置取消/确认 | 分别进入 Factory Reset 后取消、再进入后确认重置 | 取消不清除钱包；确认后钱包被清除，重启进入未激活状态 |
