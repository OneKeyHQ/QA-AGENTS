# Pro2 - Desktop/Ext 固件升级

> 规则文档：docs/qa/rules/hardware-rules.md
> 需求文档：docs/qa/requirements/Hardware-Pro2专项用例补齐.md
> 测试端：Pro2 设备端；按本份前置条件配合 iOS / Android / Desktop / Extension / Web。
> Jira 对应：OK-55011；同步字段：description。

## 前置条件

1. 使用已备份的专用 Pro2，记录种子参考地址、系统/蓝牙/Boot 版本、自动锁定、时长及自定义壁纸；每个中断点独立重试。
2. Desktop/Extension 已添加设备钱包；USB 连接，准备系统、资源及蓝牙升级组合；初始化引导升级另备未激活设备。
3. 异型号固件只使用内部允许的测试包；第三方 Trezor 升级提示仅取消，再回官方入口升级。

## 1. 升级与取消

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 系统及资源/蓝牙升级 | 分别完成系统+变更资源升级及蓝牙升级，重连并核对版本、原地址 | 目标组件版本一致；蓝牙可重新连接，设备原地址保留 |
| P1 | PIN/资源/切 Boot/安装确认取消 | 分别在错误 PIN、PIN 页取消、资源确认取消、切 Boot 取消、固件安装确认取消后重新发起升级 | 未确认阶段不继续安装；App 显示对应取消或 PIN 错误，恢复后可重新完成升级 |
| P2 | 未激活引导升级 | 在设备初始化引导中执行系统/蓝牙升级，再完成初始化 | 版本更新后仍可完成引导，升级本身不提前创建钱包 |

## 2. 中断与错误包

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| P1 | USB 推送拔线/安装关机 | 分别在固件推送拔线、安装阶段长按关机重启；再连接并重试 | App 显示传输或连接中断；可重新安装目标包，已激活设备种子与地址保留 |
| P1 | 内部异型号包校验 | 选择内部允许的异型号测试包触发升级校验，再返回官方入口使用本型号固件升级 | 非本型号包被拒绝安装或显示不兼容，不覆盖设备为其他型号；官方升级后可读取目标版本及原钱包地址 |
| P1 | 取消第三方升级提示后官方升级 | MetaMask 显示 Trezor 升级提示时取消，再进入 OneKey 官方升级入口完成本型号固件升级 | 取消后未安装第三方固件；官方升级后系统版本与目标一致，原钱包地址保留 |
