# Pro2 - 移动端固件升级

> 规则文档：docs/qa/rules/hardware-rules.md
> 需求文档：docs/qa/requirements/Hardware-Pro2专项用例补齐.md
> 测试端：Pro2 设备端；按本份前置条件配合 iOS / Android / Desktop / Extension / Web。
> Jira 对应：OK-55010；同步字段：description。

## 前置条件

1. 使用已备份的专用 Pro2，记录种子参考地址、系统/蓝牙/Boot 版本、自动锁定、时长及自定义壁纸；每个中断点独立重试。
2. iOS/Android 当前受测 App 已添加设备钱包；蓝牙执行，额外通道仅在端支持时执行；准备系统/蓝牙版本组合。
3. 资源删除组使用获准的测试设备及内部维护流程，不在普通用户设备上清理。

## 1. 移动端升级

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 系统+蓝牙/仅系统/仅蓝牙 | 分别按三种待升级组合完成升级并重新连接、核对原账户地址 | 各需升级组件显示目标版本，未选组件不被误降级；地址与升级前一致，仅蓝牙升级后原配对仍可用 |
| P1 | 取消与下次提示 | 连接设备时取消升级弹窗，再次连接并进入升级 | 本次升级未执行；版本仍旧时再次显示升级提示，可继续完整升级 |
| P1 | 设置保留 | 升级前修改锁屏、时长及壁纸，升级后逐项查看并锁屏 | 设置值及锁屏壁纸与升级前一致 |
| P1 | 缺失资源文件修复 | 在专用设备按维护流程移除部分资源，再通过 App 升级相应版本 | 资源更新后页面资源完整，缺失项重新显示且可进入各页 |

## 2. 异常与重试

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| P1 | 下载关闭蓝牙/安装关机 | 分别在下载时关闭蓝牙、安装时关闭硬件，恢复连接后重新升级 | App 显示本次中断，可重新安装至目标版本；原钱包种子与地址保留 |
| P1 | 升级时点击按键 | 安装中点击设备屏幕与按键，结束后读取版本 | 未触发未授权重置、跳过安装确认或重复安装，最终版本可读取 |
| P1 | 各阶段网络断开 | 在下载、传输、安装阶段分别断网；恢复网络后按当前流程继续或重试 | 需联网的阶段显示连接/下载错误并可重试；已具备完整安装包的阶段不损坏固件，最终可核验目标版本及原地址 |
