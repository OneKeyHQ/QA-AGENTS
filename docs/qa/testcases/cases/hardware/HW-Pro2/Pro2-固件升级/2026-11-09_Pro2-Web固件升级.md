# Pro2 -  web 固件升级

> 规则文档：docs/qa/rules/hardware-rules.md
> 需求文档：docs/qa/requirements/Hardware-Pro2专项用例补齐.md
> 测试端：Pro2 设备端；按本份前置条件配合 iOS / Android / Desktop / Extension / Web。
> Jira 对应：OK-55009；同步字段：description。

## 前置条件

1. 使用已备份的专用 Pro2，记录种子参考地址、系统/蓝牙/Boot 版本、自动锁定、时长及自定义壁纸；每个中断点独立重试。
2. Chrome WebUSB 打开 https://firmware.onekey.so/，准备官方/待发布系统固件及资源包；激活/未激活设备分别覆盖。
3. Boot 入口按受测 Pro2 的操作说明执行，AirGap 限制复用已有独立用例；不安装 Bridge。

## 1. WebUSB 升级

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 确认安装系统固件/资源包 | USB 连接，网页选择目标设备和待测固件；在设备确认升级及安装，等待自动重启；资源包有变更时一并执行 | 设备显示目标系统版本；已激活设备地址与升级前一致，未激活设备不被升级误初始化 |
| P1 | 设备取消后重试 | 在设备升级确认页点击取消，再从网页重新选择设备并确认升级 | 网页显示用户取消；重试可再次进入升级并显示目标版本 |
| P1 | 传输 9%/30%/90% 断电 | 在各进度点断电再上电，网页重新连接并完整升级 | 重启停在 Boot 升级状态，可重新安装目标固件；已激活设备原种子未被重置 |
| P1 | 100% 等待阶段断电 | 传输完成 100% 等待阶段断电，重启并读取版本和地址 | 设备进入已安装固件；目标版本与原钱包地址均可核验 |
| P1 | 资源更新中断 | 更新资源包时断电，再重新执行完整资源升级 | 资源可重新写入，重启后页面资源完整，无缺图、黑屏或循环重启 |
