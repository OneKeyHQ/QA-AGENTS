# Pro2 - 钱包重置

> 规则文档：docs/qa/rules/hardware-rules.md
> 需求文档：docs/qa/requirements/Hardware-Pro2专项用例补齐.md
> 测试端：Pro2 设备端；按本份前置条件配合 iOS / Android / Desktop / Extension / Web。
> Jira 对应：OK-54503；同步字段：description。

## 前置条件

1. Pro2 已激活，使用已备份的专用测试钱包；重置、断电或输错 PIN 场景使用独立设备状态。
2. 记录原主 PIN、标准/密语钱包地址及非默认签名手势；重置轮次放在本批其他功能之后。

## 1. 取消与重置

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 确认重置 | 设置→钱包→重置设备，继续、勾选确认并完成滑动，点击重启 | 显示设备已重置；重启进入未激活流程，旧 PIN、种子及关联 PIN 不再可用 |
| P1 | 一级/二级取消 | 分别在重置提示页、勾选确认页取消，再锁屏解锁并查看钱包 | 跳转至钱包设置，原 PIN 与种子保留，签名手势保持原所选值 |
| P1 | 重新初始化默认签名方式 | 完成重置后重新初始化并查看签名手势 | 仅默认滑动签名选中，不残留重置前的长按/点击签名设置 |
