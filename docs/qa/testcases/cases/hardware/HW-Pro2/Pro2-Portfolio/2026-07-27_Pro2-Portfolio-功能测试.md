# Pro2 - Portfolio（资产组合）

> 规则文档：docs/qa/rules/hardware-rules.md
> 测试端：Pro2 硬件（配合 OneKey App：iOS / Android / Desktop）
> 变更说明：首版——覆盖 Portfolio 开关、首页展示、金额隐藏、详情页、APP 同步、边界与异常

---

## 前置条件与测试数据

1. Pro2 已升级至包含 Portfolio 功能的固件版本；OneKey App 为支持 Portfolio 同步的最新版本
2. 设备已创建/导入钱包并完成初始化，可通过 **USB / 蓝牙** 连接 App
3. 测试账户：账户 A 多资产（≥ 7 种代币、跨多网络，如 BTC / ETH / SOL / USDC / USDT / TRX / DOGE）；账户 B 单一币种（仅 BTC）；账户 C 零资产（所有网络余额为 0）
4. 数据规则确认：代币**数量与法币价值均由 App 计算后传入**，硬件只做展示，不做汇率计算
5. 同步触发规则：**资产变化时自动同步**、**手动点击刷新按钮同步**；两次同步之间有 **20s 间隔控制**（20s 内不重复同步）；**开关关闭时同步照常进行**，仅不展示

## 5. APP 资产同步

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 首次同步（USB） | 开启开关 → USB 连接 App → 触发同步 | 1. 同步完成，硬件首页/详情页展示**当前账户**资产<br>2. 数据覆盖**所有网络**，代币数量、法币价值与 App 端完全一致 |
| ❗️❗️P0❗️❗️ | 蓝牙同步 | 通过蓝牙连接 App 触发同步 | 同 USB，数据一致 |
| ❗️❗️P0❗️❗️ | 资产变化自动同步 | 保持连接，App 端账户资产发生变化（转入/转出到账） | App **自动触发同步**，硬件数据更新为最新值，同步时间刷新 |
| ❗️❗️P0❗️❗️ | 手动刷新同步 | 保持连接，点击 App 上的**刷新按钮** | 立即触发同步，硬件数据与同步时间刷新 |
| ❗️❗️P0❗️❗️ | 20s 同步间隔控制 | 一次同步完成后，**20s 内**再次点击刷新按钮 / 触发资产变化 | 1. 20s 内**不重复同步**，硬件数据与同步时间不变<br>2. 超过 20s 后再次触发，同步执行，数据与同步时间刷新 |
| P1 | 20s 内多次资产变化 | 20s 间隔内账户资产连续变化多次 → 等待间隔结束（期间无操作） → 再手动刷新或资产再次变化 | 1. 间隔结束后**不自动补同步**，硬件仍显示旧数据<br>2. 下一次触发（刷新/资产变化）时同步携带**最新完整数据**，无中间态或丢失变更 |
| ❗️❗️P0❗️❗️ | 切换账户同步 | App 切换到另一账户（A→B）后同步 | 硬件显示**切换后账户**的资产，旧账户数据不残留 |
| P1 | 断开连接后展示 | 同步完成后断开 App 连接 | 硬件保留最近一次同步数据及同步时间，可进入详情页查看 |
| P1 | 同步中断 | 同步过程中拔掉 USB / 断开蓝牙 | 无半截数据：保持旧数据或空态，不崩溃、不显示错乱数据；重连后重新触发同步，数据更新为最新值 |
| P1 | 旧版本 App 连接 | 使用不支持 Portfolio 的旧版 App 连接 | 硬件保持未同步空态（Sync your portfolio... 提示），无异常报错 |
| ❗️❗️P0❗️❗️ | 开关关闭时仍同步 | Portfolio 关闭状态下连接 App → 资产变化 / 点击刷新按钮 → 再开启开关 | 1. 关闭状态下**同步照常触发**（同样遵守 20s 间隔控制），仅不展示<br>2. 开启开关后**直接展示关闭期间最后一次同步的数据**（含对应同步时间），与 App 端一致 |
| P2 | 多次重复同步 | 间隔 20s 以上连续触发同步 5 次 | 每次同步均完成，数据与时间逐次刷新，设备无卡顿 |

## 6. 边界与异常

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| P1 | 大量代币 | 构造 20+ 种代币账户同步 | 首页 +N 与 App 传入值一致；详情页仍只显示前 5 项 + 灰色其他段；同步耗时可接受 |
| P1 | 极小/粉尘余额 | 账户含法币价值 ≈ $0.00 的粉尘代币 | 排序与占比计算正确，不因粉尘代币导致显示异常 |
| P1 | Passphrase 隐藏钱包 | 使用 Passphrase 钱包连接 App 同步 | Portfolio 显示隐藏钱包账户数据；退出 Passphrase 后确认数据不泄漏到标准钱包（记录实际行为） |
| P1 | 多语言 | 切换设备语言（中/英）查看各页面 | 开关文案、未同步提示、View more assets 等文案均正确翻译，无缺失或截断 |
| P2 | 低电量 | 电量 <10% 时同步与浏览 | 同步与页面浏览均可执行，无异常重启 |
| P2 | 锁屏恢复 | 查看详情页时自动锁定 → 解锁 | 解锁后停留在详情页，数据显示与锁屏前一致 |
