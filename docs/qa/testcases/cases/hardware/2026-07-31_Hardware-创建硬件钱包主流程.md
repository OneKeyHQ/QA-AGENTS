# Hardware - 创建硬件钱包主流程

> 规则文档：`docs/qa/rules/hardware-rules.md`（§1 设备管理）
> 需求文档：`docs/qa/requirements/Hardware-创建硬件钱包主流程.md`
> 测试端：Desktop / Extension / iOS / Android / Web
> 变更说明：
> - 2026-07-31 首版——覆盖已激活设备连接创建钱包、默认地址创建、地址一致性核对、未激活设备激活引导；含 Pro2 未激活新流程（「设置您的设备」三步引导，按 App 入口区分创建 / 恢复文案）

---

## 前置条件与测试数据

1. 覆盖设备：Mini / Classic / Classic 1S / Touch / Pro / Pro2，电量充足
2. 已激活流程：设备已初始化、已设置 PIN 且处于**锁定状态**；未激活流程：全新或已重置（未初始化）设备
3. 覆盖端 × 连接方式：Desktop / Extension / iOS / Android / Web，USB 连接 / 蓝牙连接逐端覆盖（各端支持的连接方式与 Mini 无蓝牙等设备差异以产品实际支持为准）
4. 地址核对基线：bip39 工具或 OKX 钱包，导入与设备相同的一套助记词
5. 默认创建账户 1 地址构成：**BTC 四个路径地址 / ETH BIP44 地址 / Solana BIP44 地址 / Tron 地址**

## 1. 已激活设备：连接与 PIN 验证

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 逐端 × USB / 蓝牙标签 | 点击「连接硬件钱包」，分别选择「蓝牙」/「USB」标签 | 展示已检测到的设备列表，设备名称与型号正确 |
| ❗️❗️P0❗️❗️ | 设备已锁定 | 在列表中选择要连接的设备 | 1. App 提示输入 PIN 码<br>2. 唤起设备响应（设备进入 PIN 输入态） |
| ❗️❗️P0❗️❗️ | 输入正确 PIN 码 | 按设备型号在设备或 App 上输入正确 PIN | 1. PIN 校验通过，进入设备验证状态<br>2. 唤起设备响应 |
| P1 | 输入错误 PIN 码 | 输入错误 PIN | 1. 提示 PIN 错误，可重试<br>2. 不进入设备验证状态 |
| ❗️❗️P0❗️❗️ | 设备端确认验证 | 在设备上点击「确认」 | 1. 设备验证通过<br>2. 验证页面内容显示正确（设备型号、验证状态等与设计稿一致） |
| P1 | 设备端拒绝 / 中断 | 在设备验证状态下于设备上取消，或断开 USB / 蓝牙连接 | 1. 流程中断，App 给出对应提示<br>2. 可返回设备列表重新连接，无卡死 |

## 2. 已激活设备：创建钱包与默认地址

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 验证通过后创建钱包 | 点击「继续」 | 1. 进入创建钱包 loading 页面<br>2. 钱包创建完成，跳转至钱包首页，钱包列表数量 +1 |
| ❗️❗️P0❗️❗️ | 默认账户地址构成 | 查看默认创建的**账户 1** | 账户 1 下创建：**BTC 四个路径地址 / ETH BIP44 地址 / Solana BIP44 地址 / Tron 地址** |
| P1 | 网络选择其他链时创建钱包 | 先切换到非默认链（如 Cosmos / TON 等），再连接设备创建钱包 | 当前选中链与默认地址（BTC / ETH / Solana / Tron）一起创建 |
| P1 | 切换账户 / 切换链不自动创建 | 1. 切换到账户 2 或未创建地址的链<br>2. 点击创建 | 1. 切换后**不自动创建**地址，显示创建入口<br>2. 点击后需设备确认的链唤起设备，确认后列表显示新建地址 |

## 3. 已激活设备：地址一致性核对

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | bip39 / OKX 对账 | 1. 将同一套助记词导入 bip39 工具或 OKX 钱包<br>2. 逐链核对已创建地址（BTC 四路径 / ETH / Solana / Tron 及其他已创建链） | 所有链地址与 bip39 / OKX 推导结果**完全一致** |

## 4. 未激活设备：激活引导（Mini / Classic / Classic 1S / Touch / Pro）

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 未激活设备连接 | 点击「连接硬件钱包」，选择「蓝牙」/「USB」标签，选择未激活设备 | 1. 展示已检测到的设备列表<br>2. 选择后唤起设备响应，进入设备验真状态 |
| ❗️❗️P0❗️❗️ | 设备端确认验真 | 在设备上点击「确认」 | 1. 设备验真通过<br>2. 验真页面内容显示正确 |
| ❗️❗️P0❗️❗️ | 激活引导页 | 点击「继续」 | 弹出激活引导页面，显示「创建钱包」与「恢复钱包」按钮 |
| ❗️❗️P0❗️❗️ | 逐设备核对创建说明页 | 点击「创建钱包」 | 进入创建钱包说明页面，**不同设备对应不同说明页面**，页面内容正确 |
| P1 | 逐设备核对恢复说明页 | 点击「恢复钱包」 | 进入恢复钱包说明页面，**不同设备对应不同说明页面**，页面内容正确 |
| P1 | 获取帮助 | 点击「获取帮助」 | 跳转官网帮助中心 |

## 5. Pro2 未激活设备：「设置您的设备」三步引导（新流程）

> Pro2 未激活不走第 4 节的激活引导页，改为 App 侧「设置您的设备」时间线引导页（完善基础设置 → 创建 PIN 码 → 设置钱包），由设备端操作驱动 App 侧步骤推进。

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 进入三步引导页 | 连接未激活 Pro2，完成验真后继续 | 1. 进入「设置您的设备」页面，时间线展示三步：**完善基础设置 / 创建 PIN 码 / 设置钱包**<br>2. 首步「完善基础设置」高亮，说明为「请选择语言，然后为您的设备命名。」，底部设备图标提示「请在设备上继续」 |
| ❗️❗️P0❗️❗️ | 完善基础设置 | 在 Pro2 设备上完成语言选择和设备命名 | 1. App 侧「完善基础设置」步骤打**绿色对勾**<br>2. 自动推进到「创建 PIN 码」步骤高亮 |
| ❗️❗️P0❗️❗️ | 创建 PIN 码 | 在 Pro2 设备上创建并确认 PIN | 1. 「创建 PIN 码」步骤打绿色对勾<br>2. 推进到「设置钱包」步骤高亮 |
| ❗️❗️P0❗️❗️ | 设置钱包步骤展示 | 查看「设置钱包」步骤内容 | 1. 说明为「创建新钱包，或恢复已有钱包：」<br>2. 列出两个选项：「**创建新钱包**：在设备上生成新的助记词。」「**恢复钱包**：从助记词或 SeedCard 恢复。」<br>3. 底部提示「请在设备上选择一个选项」 |
| ❗️❗️P0❗️❗️ | 按入口区分文案：创建 | 从 App「创建钱包」入口进入三步引导，走到「设置钱包」步骤 | 「设置钱包」步骤显示与**创建**入口对应的文案（以设计稿为准） |
| ❗️❗️P0❗️❗️ | 按入口区分文案：恢复 / 导入 | 从 App「恢复钱包 / 导入」入口进入三步引导，走到「设置钱包」步骤 | 「设置钱包」步骤显示与**恢复 / 导入**入口对应的文案（以设计稿为准），与创建入口文案不同 |
| ❗️❗️P0❗️❗️ | 设备端完成创建后回连 | 在设备上选择创建新钱包，完成助记词生成与备份 | 1. App 侧引导完成，进入创建钱包 loading<br>2. 钱包创建完成，进入钱包首页，默认账户地址构成同第 2 节 |
| P1 | 设备端选择恢复 | 在设备上选择从助记词或 SeedCard 恢复，完成恢复 | App 侧引导完成，钱包显示在钱包列表中，地址与该助记词的 bip39 / OKX 推导一致 |
| P1 | 引导中途断开 | 三步引导进行中断开 USB / 蓝牙 | 1. App 给出连接中断提示，无卡死<br>2. 重新连接后可继续或重新进入引导，设备端已完成的步骤（语言 / PIN）状态保持 |
| P2 | 退出引导再进入 | 引导中途返回 / 关闭 App 侧引导页，再重新连接设备 | 重新进入引导页，步骤状态与设备端实际进度一致 |

---

## 预期结果汇总

1. 已激活设备连接后创建钱包成功，默认账户地址构成正确
2. 未激活设备（Mini / Classic / Classic 1S / Touch / Pro）连接后提示激活引导页面；Pro2 走「设置您的设备」三步引导，且按创建 / 导入入口提示不同文案
3. 连接硬件钱包地址数据与 bip39 或 OKX 核对一致
