## 前置条件与测试数据

1. App 5.20.0 已安装；HW 钱包已初始化、电量充足
2. 覆盖设备：Pro2 / Pro（黑款、白款）/ Touch / Classic/1S / Mini / Pure；涉及型号差异的用例统一按下方「设备差异总表」逐型号核对
3. QR 钱包用例需提前用同一设备创建 QR 钱包

| --- | --- | --- | --- | --- | --- | --- |

| 语言 / 自动锁定 / 自动关机 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| 亮度 | ✓ | ✓ | ✓ | ✗ | ✗ | ✗ |
| 振动反馈 | ✓ | ✓ | ✓ | ✗ | ✗ | ✗ |
| Passphrase | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| 在 App 上输入 PIN 码 | ✗ | ✗ | ✗ | ✓ | ✓ | ✗ |
| 认证信息（如 EAL 6+，关于设备弹窗） | ✓ | ✓ | ✗ | ✓ | ✗ | ✓ |
| 存储用量 / FCC ID（关于设备弹窗） | ✗ | ✗ | ✗ | ✓ | ✗ | ✗ |
| 清除设备数据（危险区域，需设备确认） | ✓ | ✓ | ✗ | ✓ | ✗ | ✓ |

| P1 | Pro / Touch | 分别切换振动反馈为开 / 关 | 1. 硬件显示确认页（按钮 Cancel / Open 或 Close）<br>2. 确认后开关状态更新 |

## 5. Passphrase 开启 / 关闭

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | Passphrase 开关关闭 | 1. 设备详情页 > 高级设置区域点击 Passphrase 开关<br>2. App 弹窗点击 Confirm<br>3. 硬件点击 Enable | 1. App 显示「开启 Passphrase」弹窗，含隐藏钱包说明与风险提示（忘记 Passphrase 资金永久丢失），按钮 Cancel / Confirm<br>2. 硬件显示开启确认页，按钮 Cancel / Enable<br>3. 确认后开关更新为开启 |
| ❗️❗️P0❗️❗️ | Passphrase 开关开启 | 同上流程执行关闭（硬件点击 Disable） | 1. App 显示「关闭 Passphrase」弹窗，提示：Passphrase 钱包仍在链上、需重新开启并输入才能访问、忘记则资金永久丢失，按钮 Cancel / Confirm<br>2. 硬件显示关闭确认页，按钮 Cancel / Disable<br>3. 确认后开关更新为关闭 |
| P1 | App 弹窗 / 硬件确认页 | 分别点击 Cancel | 开关保持原状态，弹窗关闭 |

## 7. 移除设备

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 已连接设备 | 1. 设备详情页「设备连接」区域点击「移除设备」<br>2. 核对弹窗内容 | 1. 弹出移除确认弹窗<br>2. 将会发生：设备断开连接并从列表移除、活动会话停止<br>3. 保持安全：恢复短语与资金不受影响、可随时重新配对<br>4. 显示取消 / 确认移除按钮 |
| ❗️❗️P0❗️❗️ | 移除确认弹窗已打开 | 点击确认移除 | 1. 设备从列表移除，返回设备管理列表<br>2. 显示移除完成的 Toast 提示<br>3. 仅删除 App 内记录，硬件设备数据与恢复短语不受影响 |
| ❗️❗️P0❗️❗️ | 设备已被移除 | 点击「添加设备」重新配对该设备 | 设备重新出现在列表，设备信息与移除前一致 |
| P1 | 移除确认弹窗已打开 | 点击取消 | 弹窗关闭，设备保持连接 |

## 8. 危险区域

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | Pro2 / Pro / Classic 1S / Pure | 1. 设备详情页「危险区域」点击「清除设备数据」<br>2. 在设备上确认 | 1. App 显示清除数据风险提示<br>2. 设备显示确认页，确认后设备数据清除、恢复未初始化状态<br>3. App 侧对应钱包按设备重置规则处理 |
| ❗️❗️P0❗️❗️ | Pro2 / Pro / Classic 1S / Pure | 点击「切换到比特币专用固件」 | 引导进入固件升级切换流程，跳转至对应升级页面 |
| P1 | 清除数据设备确认页 | 在设备上取消 | 数据保留，设备与连接状态不变 |
| P2 | Touch / Mini | 查看设备详情页 | 不显示「危险区域」的清除设备数据、切换到比特币专用固件入口 |
