# DeFi - Aave 借贷市场

> 规则文档：`docs/qa/qa-rules.md`、`docs/qa/rules/defi-rules.md`（第 3 章 Aave）
> 需求引用：`docs/qa/requirements/DeFi-Aave协议.md`
> 测试端：默认全端
> 变更说明：覆盖市场切换（Aave Core / Aave Arbitrum，Base 已下线）、借币首页、资产详情页、存入 / 借币 / 赎回 / 偿还、抵押品开关、E-Mode 管理、健康系数与市场隔离

## 前置条件与测试数据

1. 已导入 HD 钱包，Ethereum 主网与 Arbitrum 网络均已创建地址（同派生路径分别创建，两网 gas 均为 ETH）；核心流程（存入 / 借币 / 赎回 / 偿还 / E-Mode 切换 / 抵押开关）**使用有余额的 HD 钱包账户真实签名 + 广播执行**；钱包密码弹窗按通用规则自动处理
2. 入口：DeFi → 「借币」tab → 顶部市场选择器（Aave Core / Aave Arbitrum / Kamino Main；市场名由后端返回，前端会去掉尾部 `Market` / `Instance` 字样，如 `Aave Core Market` 显示为 `Aave Core`）；**市场参数化**：除注明「仅 Core」「仅 Arbitrum」的场景外，第 5～10 章核心流程需在 Aave Core（Ethereum `evm--1`）与 Aave Arbitrum（Arbitrum `evm--42161`）各执行一遍，用例不按市场复制
3. 需准备 4 类账户状态（每个市场各一套或可切换数据集）：空仓（无存入无借款）/ 有余额无存借 / 有存入无借款 / 有存入有借款（健康系数 ≥ `1.50`）
4. 测试资产：原生 ETH + 至少 2 种 ERC-20（如 Core：USDT / USDC / DAI / cbBTC；Arbitrum：USDC / USDT / WETH / wstETH / ARB / WBTC，以实际列表为准），其中至少 1 种可作抵押品、1 种不可作抵押品；原生 ETH 场景仅在 Core 执行
5. E-Mode：Core 类别（ETH correlated 93% / sUSDe Stablecoins 90% / LBTC WBTC 84% 等）、Arbitrum 类别以实际返回为准；需准备「借款资产在目标类别内（无冲突）」与「借款资产不在目标类别内（有冲突）」两种仓位

## 5. 存入流程（Core / Arbitrum 参数化）

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 存入弹窗与金额边界 | 1. 点击 ERC-20 资产「存入」<br>2. 依次输入 `0`、超余额金额、有效金额<br>3. 点击最大值 | 1. 金额 `0` / 空：按钮置灰<br>2. 超余额：显示余额不足提示，按钮置灰<br>3. 有效金额：显示 USD 估值，按钮启用<br>4. 最大值：填入全部可用余额（原生 ETH 预留 gas） |
| ❗️❗️P0❗️❗️ | ERC-20 首次存入需授权 | 1. 用未授权过的 ERC-20 输入有效金额<br>2. 观察底部<br>3. 提交 | 1. 输入金额后底部出现两步进度条：① 授权 ② 存入（桌面与按钮同行，手机在按钮上方），按钮文案「授权」<br>2. 授权交易确认上链后自动进入存入交易确认，进度条走到第 2 步<br>3. 已授权（额度足够）时无进度条，直接进入存入确认，不重复授权 |
| ❗️❗️P0❗️❗️ | 确认信息「用作抵押」三态 | 1. 分别对 不可抵押资产 / 已开启抵押的可抵押资产 / 未开启抵押的可抵押资产 打开存入弹窗<br>2. 观察信息区「用作抵押」行 | 1. 不可抵押：红色 ✕「不可用」<br>2. 可抵押且已开启：绿色 ✓「已启用」<br>3. 可抵押但未开启：黄色 ✕「已禁用」<br>4. 后端未返回抵押状态时该行不显示 |
| P1 | ERC-20 存入成功 | 1. 确认存入交易并广播 | 1. 交易确认后我的存入新增 / 累加该资产行，数量与输入一致<br>2. 净值、健康系数（如有借款）同步更新<br>3. 历史记录新增存入记录（资产 / 数量 / 时间 / 状态） |
| P1 | 原生 ETH 存入成功（仅 Core） | 1. 选择 ETH 输入有效金额并提交 | 1. **无授权步骤**，直接进入交易确认<br>2. 交易确认后我的存入出现 ETH 行，钱包 ETH 余额扣减金额 + gas |
| P1 | 资产选择弹窗 | 1. 在存入弹窗打开资产选择<br>2. 点击当前已选资产<br>3. 选择 wstETH / cbBTC 等混合大小写资产 | 1. 点击当前资产直接关闭弹窗回到存入页<br>2. 选择器与弹窗显示的 symbol 保持原始大小写（`wstETH`、`cbBTC`），不强制大写 |
| ❗️❗️P0❗️❗️ | 存入上限已满 | 1. 对存入上限使用 100% 的资产尝试存入 | 1. 显示上限已满提示（提示文案由后端 alerts 返回），按钮置灰或提交被拦截 |
| P2 | 断网 / 接口异常 | 1. 断网状态下打开存入弹窗并提交 | 1. 显示网络错误提示，不发起交易，恢复后可重试 |

## 6. 借币流程（Core / Arbitrum 参数化）

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 借币弹窗与健康系数预览 | 1. 有抵押账户点击「借币」<br>2. 输入有效金额并逐步增大 | 1. 显示可借额度<br>2. 健康系数随金额实时下降（before → after 预览）<br>3. 有效金额时按钮启用 |
