# Utility - 旅行模式测试用例

> 需求文档：`docs/qa/requirements/Utility-旅行模式.md`
> 规则文档：`docs/qa/rules/utility-rules.md` §2.5
> 测试端：iOS / Android
> 更新日期：2026-10-30

## 前置条件

1. 准备 iOS 和 Android 移动端，已创建钱包、收藏和浏览记录。
2. 准备正确/错误 PIN，确认设备支持重启后重新进入 App。
3. 记录开启前 App 图标、账户、收藏、浏览记录和 App 状态。

## 1. 入口与 PIN 验证

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 正确 PIN 开启 | 1. 打开旅行模式<br>2. 输入正确 PIN | 开启流程通过并触发 App 重启 |
| P1 | 移动端入口 | 进入设置 → 安全 | 显示旅行模式入口 |
| P1 | 错误 PIN 开启 | 输入错误 PIN | 开启失败，旅行模式保持关闭 |
| P1 | 生物识别替代 PIN | 在开启流程尝试使用生物识别 | 不允许使用生物识别替代 PIN |
| P1 | 非移动端 | 在桌面端或 Web 端进入设置 | 不显示旅行模式入口 |

## 2. 开启后的隐私与导航

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 锁定相关功能 | 在旅行模式下执行锁定相关操作 | 锁定相关功能失效 |
| P1 | App 重启与图标 | 开启旅行模式并等待 App 重启 | App 重启完成，图标替换为旅行模式图标 |
| P1 | 个人信息隐藏 | 进入钱包账户、收藏、浏览记录等页面 | 不显示对应个人信息 |
| P1 | 一级页面切换 | 在旅行模式下切换 App 一级页面 | 一级页面可点击切换 |
| P1 | 二级页面 | 进入或操作二级页面 | 不增加旅行模式专属限制或要求 |

## 3. 关闭与状态恢复

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 关闭后恢复 | 关闭并等待 App 重启 | 恢复原 App 图标、钱包账户、收藏、浏览记录和关闭前 App 状态 |
| ❗️❗️P0❗️❗️ | 正确 PIN 关闭 | 1. 进入关闭旅行模式流程<br>2. 输入正确 PIN | 关闭流程通过并触发 App 重启 |
| P1 | 关闭时使用生物识别 | 在关闭流程尝试使用生物识别 | 不要求或不接受生物识别，按 PIN 流程处理 |
| P1 | 错误 PIN 关闭 | 输入错误 PIN | 关闭失败，旅行模式保持开启 |
