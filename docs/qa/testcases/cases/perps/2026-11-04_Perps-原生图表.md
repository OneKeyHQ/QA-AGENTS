# Perps - 原生图表

> 规则文档：`docs/qa/rules/perps-rules.md` §13；`docs/qa/rules/perps-native-chart-performance.md`。
> 需求文档：`docs/qa/requirements/Perps-代码审查补充能力.md` §2。
> 测试端：Desktop / iOS / Android。
> 数据样本：[原生图表固定样本v1](../../../test-data/perps/native-chart-v1/README.md)。
> 范围：99条；2026-11-05已落实R01–R09全部审查意见并简化描述。17类指标具体默认参数仍未纳入。

## 前置条件

1. 使用独立测试配置验证首次状态；记录包版本及原有设置，结束后恢复并读回。
2. 固定计算与绘图使用《原生图表固定样本v1》；成交与挂单使用当前账户同市场、同时间桶的独立记录；参数集逐项执行。
3. 默认Desktop原生主图或iOS/Android全页图；端与布局差异按场景执行，移动外观页不套用桌面弹窗，轻量图只执行对应章节。
4. 只读、输入和预览不提交交易；真实改撤单另批确认账户、订单、价格及允许改动项，使用有余额且已启用交易的HD账户；授权取消和故障组按各自前置。
5. 性能测试带宽≥20Mbps、RTT≤100ms、丢包<1%，无并行操作；故障和容量测试使用可恢复的独立配置。
