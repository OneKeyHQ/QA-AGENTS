## 前置条件与测试数据

1. **账户**：已连接 HD 钱包 / HW 钱包 / 私钥钱包 / Keyless 钱包任一种，且已创建 EVM 地址
2. **资产**：账户在 Hyperliquid 有 USDC 余额，且至少持有一种现货代币
3. **客户端**：桌面端（TestFlight / MAS / 浏览器插件）、移动端（iOS / Android）、Web
4. **范围**：现货模式不支持触发单、止盈止损附单、杠杆、爆仓价、持仓线
5. **接口自动化**：现货下单接口参数已由接口自动化覆盖，本文件只验证界面行为与余额 / 挂单变化
