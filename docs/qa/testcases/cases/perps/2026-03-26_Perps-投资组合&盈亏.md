## 8. 账户健康风险等级（组合评分）

> 总分 = MMR 分 ×3 + 杠杆分 ×2 + 已用保证金分 ×1，各分项取 0 / 1 / 2：MMR ≤ 30% → 0、≤ 60% → 1、> 60% → 2；杠杆 ≤ 5x → 0、≤ 15x → 1、> 15x → 2；已用保证金 ≤ 60% → 0、≤ 85% → 1、> 85% → 2。总分 ≥ 6 为「高风险」，≥ 3 为「中等风险」，否则「健康」；仅有持仓时显示等级。
