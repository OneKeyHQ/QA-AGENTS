## 前置条件

- **支持端**：基础搜索在 iOS / Android / Desktop / Extension / Web 执行；§8–11 快捷键与桌面弹层布局在 Desktop / Extension / Web 执行，移动端仅执行 §11 的触屏回归。
- **快捷键与数据**：从交易对入口打开搜索弹层；macOS 收藏键为 ⌘S，Windows / Linux 为 Ctrl+S（下文统称收藏快捷键）。准备至少 3 条自选、永续及现货结果和跨屏长列表；记录原收藏及当前交易对，用例结束后恢复。
- **弹窗结构**：顶级 tab「自选 / 永续合约 / 现货」；子级 tab 只在「永续合约」下出现：「全部」及服务端下发的热门 / 新上架 / 加密货币 / 股票 / 贵金属等；自选与现货无子级 tab
- **中文标签**：由服务端按界面语言下发，客户端缓存 5 分钟；切换语言后需重启 App 或等待 5 分钟再验证

## 8. 快捷键导航与代币选择

仅 Desktop / Extension / Web。「选中」指列表当前可操作的高亮项；仅按 Enter 或点击代币才切换交易对。

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 打开与切换分类后默认首项 | 1. 打开搜索弹层，分别切换有结果的自选 / 永续合约 / 现货及永续子分类<br>2. 每次列表加载完成后不按方向键，直接按 Enter | 1. 每次默认仅选中当前列表第一项，Enter 可用<br>2. Enter 选择该项并关闭弹层，交易页显示其资产及永续 / 现货模式 |
| ❗️❗️P0❗️❗️ | 上下导航后选择代币 | 在自选 / 永续 / 现货的至少 3 条结果中，依次按 ↓、↓、↑，再按 Enter | 1. 高亮按当前展示顺序逐项移动，任意时刻仅一项选中<br>2. Enter 选择最终高亮项，页面头部、图表与下单面板使用同一交易对；不提交订单 |
| P1 | 单条结果及首尾导航 | 筛选到仅 1 条结果反复按 ↑ / ↓；再在多条结果的首项 / 末项按 ↑ / ↓ | 单条结果保持唯一选中；多条结果不出现越界、空选中或同时高亮两项，Enter 选择当前高亮项 |

## 10. 快捷键收藏与取消后的定位

收藏快捷键只修改当前高亮资产的自选状态。自选取消后，顶部连续取消跟随下一项，底部连续取消跟随上一项；每条用例结束后恢复原收藏。

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 收藏与取消当前高亮资产 | 在永续 / 现货结果选中未收藏资产，按收藏快捷键，待状态更新后再按一次 | 1. 两次分别添加及取消该资产，星标、自选列表与顶部收藏栏同步更新<br>2. 弹层保持打开，交易对不切换，不误改相邻资产或唤起浏览器保存页面 |
| P1 | 自选顶部连续取消 | 将至少 3 条自选排序为 A、B、C，选中 A 后连续逐次按收藏快捷键，每次等待移除完成 | A 移除后自动选中 B，B 移除后自动选中 C；不需额外按方向键即可连续取消 |
