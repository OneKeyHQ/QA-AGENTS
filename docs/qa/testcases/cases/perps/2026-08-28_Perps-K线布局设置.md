# Perps - K 线布局设置（移动端 K 线位置 / 桌面端面板高度）

> 生成时间：2026-08-28
> 规则文档：`docs/qa/rules/perps-rules.md`（§10 K 线布局规则）
> 需求文档：`docs/qa/requirements/Perps-K线布局设置.md`
> 测试端：iOS / Android / 小屏 Web（第 1–7、11 章移动端部分）；Desktop / 大屏 Web（第 8–11 章）
> 变更说明：首版——移动端与小屏 Web 交易页 K 线位置（顶部 / 底部 / 不展示）、桌面端分隔线拖动与重置、图表全屏、新功能引导；代码推导场景已经产品确认并入（2026-08-28）；默认位置按产品确认改为**底部**（源码 x 分支当前为顶部，**已确认 bug，已上报，未修复前该用例预期 failed**）

---

## 前置条件与测试数据

1. 已解锁钱包并进入「合约」页，当前交易对有行情数据（如 SNDK / NVDA / ETH 永续）
2. 移动端章节在 iOS / Android 真机及小屏 Web（窗口宽度 < md 断点）执行；桌面端章节在 Desktop 与大屏 Web（≥ md）执行
3. 引导类用例需新安装 App 或清除 App 数据后首次进入合约页
4. 桌面端最小高度：图表区 360 px、信息区 300 px；移动端图表高度 200–250 px 按视口自适应

## 1. 移动端 布局设置入口与选项

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 移动端合约页 | 1. 点击行情栏「更多」<br>2. 点击「布局设置」 | 1. 「更多」菜单包含「布局设置」入口<br>2. 弹窗显示「布局设置」，分组标题「交易页 K 线」<br>3. 显示三个选项：顶部 / 底部 / 不展示，各带布局示意图 |
| ❗️❗️P0❗️❗️ | 在「布局设置」弹窗 | 依次点击「底部」「不展示」「顶部」 | 1. 被点击项切换为选中，其余未选中，同一时刻仅一个选中<br>2. 关闭弹窗后交易页即时切换为对应布局，不需要刷新或重进 |
| ❗️❗️P0❗️❗️ | 首次安装、从未设置过 K 线位置 | 打开「布局设置」 | 1. 「底部」选中<br>2. 交易页按底部布局显示：页面底部显示入口条，行情栏不显示图表按钮 |
| P1 | 小屏 Web（窗口宽度 < md） | 打开「更多」 | 显示「布局设置」，三种位置行为与移动端一致 |
| P1 | 旧版本已保存「顶部」 | 升级后进入合约页 | 仍为「顶部」布局，「顶部」选中（已保存偏好不受默认值影响） |
| P1 | Desktop / 大屏 Web | 打开设置菜单 | 不显示「布局设置」/「交易页 K 线」入口 |

| 优先级 | 场景 | 操作步骤 | 预期结果 |

| ❗️❗️P0❗️❗️ | 顶部 K 线已展开 | 依次点击周期 1分 / 15分 / 1时 / 4时，再点击「更多」选择其他周期 | 周期选中态切换，K 线按新周期刷新 |
| ❗️❗️P0❗️❗️ | 顶部 K 线已展开 | 滚动页面到买入 / 卖出按钮并点击数量输入框 | 1. 交易面板、买入 / 卖出按钮可点击<br>2. 输入框可获得焦点 |
| P1 | 顶部 K 线已展开 | 查看图表内控件 | 图表内不显示关闭按钮，仅行情栏按钮可收起 |
| P1 | 顶部 K 线已展开 | 离开合约页再返回 | K 线为收起状态，按钮为收起态 |
| P2 | 长屏设备与短屏设备（视口高度 ≤ 700 px）各一次 | 展开顶部 K 线并量图表高度 | 1. 长屏图表高度 250 px<br>2. 短屏按视口缩小，最小 200 px，行情栏保持可见 |

## 11. 新功能引导

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 移动端首次进入合约页 | 1. 查看行情栏「更多」按钮<br>2. 点击「更多」<br>3. 查看菜单内「布局设置」入口<br>4. 点击「布局设置」 | 1. 「更多」按钮显示提示点<br>2. 打开菜单后「更多」按钮提示点消失<br>3. 「布局设置」入口显示提示点<br>4. 点击后提示点消失 |
| ❗️❗️P0❗️❗️ | 桌面端首次进入合约页 | 等待约 1 秒后查看分隔线 | 1. 分隔线中部显示高亮条 + 气泡文案「拖动分隔线可调整图表和持仓区域的高度。」<br>2. 页面其余区域变暗 |
| P1 | 两处提示点已消失 | 杀进程重进合约页 | 「更多」按钮与「布局设置」入口均不显示提示点 |
| P1 | 桌面端提示显示中 | 1. 关闭提示（或拖动分隔线）<br>2. 刷新页面 | 1. 提示消失<br>2. 刷新后不再显示提示 |
| P1 | 桌面端首次进入且图表处于全屏 | 查看分隔线区域 | 不显示提示；退出全屏后显示 |
| P1 | 移动端仅打开「更多」未点「布局设置」 | 关闭菜单后杀进程重进 | 「更多」按钮无提示点；打开菜单后「布局设置」入口仍显示提示点 |
