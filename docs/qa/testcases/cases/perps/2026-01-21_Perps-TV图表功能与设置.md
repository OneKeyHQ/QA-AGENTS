## 前置条件

- Desktop / 大屏 Web / Extension 展开页的图表，以及移动端点击行情栏「K线」按钮进入的全页图表，支持 TradingView / 原生版切换；§1–9 执行前明确选中 TradingView，§10 验证原生版，不以 TradingView 指标或工具断言原生版。
- 当前统一工具栏位于 OneKey 主页面，两种引擎共用周期与指标入口；指标按主图 / 副图分类，周期偏好通过「编辑」维护。当前面板不套用旧版星形收藏或自定义周期入口；以下按分类选中状态和偏好周期编辑验收。
- 移动端交易页内嵌 K 线（顶部 / 底部）为原生轻量图表：无成交量指标、指标管理、画图工具、仓位 / 订单线、买卖点，周期固定 9 档、默认 1时。本文用例不在内嵌 K 线执行，其用例见 `2026-08-28_Perps-K线布局设置.md`。
- 「在图表上显示买卖点」「在图表显示仓位和订单」开关入口：Desktop / 大屏 Web 为行情栏「···」菜单与右上角账户面板「合约」分组；移动端为行情栏「···」菜单。开关对 compact 内嵌 K 线无效；主图与全页图表的原生版另按 §10 验证。
