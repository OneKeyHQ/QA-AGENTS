# Perps - Unifold 充值（链上收款）

> 生成时间：2026-08-03
> 规则文档：`docs/qa/rules/perps-rules.md`（§9）
> 需求文档：`docs/qa/requirements/Perps-Unifold充值.md`（app-monorepo PR #12602 / #12634 / #12682 / #12697）
> 测试端：Desktop / Web / Android / iOS / Extension
> 变更说明：首版——覆盖入口与开关、代币网络选择、转入页信息、最小金额到账语义、链上存款记录与详情

---

## 前置条件与测试数据

1. 已登录 HD 钱包并完成 HL 启用交易；服务端已下发 `unifoldDepositEnabled=true`；数据对照基准：hl + 来源链区块浏览器
2. 外部资金源：Arbitrum USDC ≥ $5（验证最低 $3 网络）+ 少量 BTC（验证跨币种兑换路径）
3. 参考数据：Arbitrum USDC 合约 `0xaf88d065e77c8cc2239327c5edb3a432268e5831`；USDC 最低存款：Ethereum $10，Base / Arbitrum / Polygon / Optimism / BSC $3
4. 到账语义：单笔 < 最低金额不立即到账，同一地址累计达到最低金额后合并到账

## 4. 到账与最小金额语义

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 单笔 ≥ 最低金额 | 1. 向存款地址转入 Arbitrum USDC $3<br>2. 等待处理完成 | 1. Perps 可用余额增加 ≈$3（扣除手续费后）<br>2. 链上存款记录新增一条「存款已完成」，金额与时间与实际一致 |
| ❗️❗️P0❗️❗️ | 单笔 < 最低金额，累计合并到账 | 1. 向同一地址转入 $1（低于 $3）<br>2. 确认未到账后再转入 $2.5 | 1. 第一笔不立即到账，Perps 余额不变<br>2. 累计 $3.5 ≥ $3 后**合并到账**，余额一次性增加 ≈$3.5<br>3. 记录中可追踪各笔状态 |
| P1 | 非 USDC 代币充值 | 1. 转入 BTC（≥ 该网络最低金额） | 1. 按存款路径兑换为 USDC (Perp) 入账<br>2. 到账金额 = 兑换值扣除第三方手续费<br>3. 详情内发送数量为 BTC、收到数量为 USDC (Perp) |
| P1 | 转入页开着时的状态反馈 | 1. 转账后保持转入页打开 | 1. 面板内显示该笔执行的状态卡片，随状态推进更新<br>2. 状态卡片不遮挡「条款/帮助」行 |
| P1 | 关闭转入页后的通知 | 1. 转账后关闭转入页<br>2. 等待处理完成 | 1. 完成时收到标准 Perps toast 通知<br>2. 与面板状态卡片不重复通知 |
| P1 | 充值失败 | 1. 构造失败场景（联系后端标记） | 1. Toast 提示联系支持并附**参考编号** |
