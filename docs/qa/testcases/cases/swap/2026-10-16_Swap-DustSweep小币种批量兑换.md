## 测试范围说明

**功能范围**：钱包内将小额代币批量兑成当前链 gas token（Dust Sweep）。
**测试重点**：入口不在 Trade；档位与门槛；隐藏代币一次性加入；排除 gas token / LP / 风险币；Convert 串行执行；Stop / 离开不持久化；Review Order 二次确认情形一律跳过；完成态分端与计数。
**不覆盖**：单笔 Swap Review Order 全量回归、OKX 渠道报价矩阵、Trade 页主流程。
**金额档位**：`<$1` / `<$10`（默认）/ `<$100` 写在各表步骤内，不另立边界章节。

## 前置条件

- 已登录软件钱包；当前网络 OKX 同链报价可用；账户有足够链 gas token 支付网络费。
- 准备样本：估值落在档位内的可清扫代币；Ethereum 上 `$0.05`（低于 `$0.1`）与其他链 `$0.005`（低于 `$0.01`）；风险币；LP / 协议仓位；当前链 gas token 小额余额。
- 渠道暂固定 OKX；目标币为链 gas token，页面无切换入口。
