# Swap - BTC 交易灵动岛

> 需求文档：`docs/qa/requirements/Swap-BTC交易灵动岛.md`  
> 规则文档：`docs/qa/rules/swap-rules.md` 第 `4.5` 节  
> 测试端：iOS 16.1+（灵动岛：iPhone 14 Pro 及以上；无灵动岛机型：锁屏 / 通知中心）  
> 更新日期：2026-11-24  
> 需求：[OK-60951](https://onekeyhq.atlassian.net/browse/OK-60951)

## 前置条件

1. 使用已解锁的软件或硬件钱包均可；本功能不按钱包类型拆分。
2. 系统为 iOS 16.1+；验证灵动岛时使用 iPhone 14 Pro 及以上，并开启 OneKey「实时活动」。
3. 账户持有可兑换的 Bitcoin 主网原生 BTC；可完成一笔 BTC → 稳定币（如 USDC）的 Swap / Bridge。
4. 当前页面文案按设计稿英文状态验收（`Confirming on Bitcoin network` / `Done` / `Refunded` 等）。

## 测试数据

| 数据 | 取值 |
|------|------|
| 标杆币对 | BTC（Bitcoin 主网）→ USDC |
| 紧凑态 ETA 停留 | 出现及每次状态更新后 3 秒 |
| ETA 取整 | 剩余 4 分 20 秒显示 ≈5 min |
| Almost done | 剩余时间 &lt; 10s |

| 预估时长缺失兜底 | 10 分钟 |
| Ticker 截断 | 超过 6 个字符显示 ABCDEF… |
