# Prime - 功能试用额度测试用例

> 需求文档：`docs/qa/requirements/Prime-功能试用额度.md`
> 规则文档：`docs/qa/rules/prime-rules.md` §4.15
> 测试端：iOS / Android / Desktop / Extension / Web
> 更新日期：2026-10-30

## 前置条件

1. Dashboard 可配置功能开关、次数额度、DApp 翻译 token 额度和月度重置时间。
2. 准备已登录/未登录账号、额度充足/不足账号，以及可构造失败、部分成功和异常退出的测试数据。

## 1. 功能入口与资格

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 未登录且功能试用已开启 | 点击批量复制地址、批量发送、批量取消授权、地址风险检查或 DApp 翻译入口 | 显示登录弹窗，不直接执行功能 |
| ❗️❗️P0❗️❗️ | 额度不足 | 进入已耗尽额度的功能 | 提示额度不足和下次重置时间，并跳转 Prime 购买页 |
| P1 | 未登录且功能不支持或未开启 | 点击对应功能入口 | 显示 Prime 购买页面 |
| P1 | 已登录且额度充足 | 执行支持试用的功能 | 进入功能流程并按规则锁定/扣减额度 |

## 2. 额度统计与扣减

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| ❗️❗️P0❗️❗️ | 完全成功 | 完成批量操作 | 按实际完成项目数量扣减额度 |
| ❗️❗️P0❗️❗️ | 功能失败 | 执行失败操作 | 不扣减使用额度 |
| P1 | 次数额度功能 | 分别执行批量复制地址、批量发送、批量取消授权、地址风险检查 | 按使用次数统计；支持的功能展示剩余额度 |
| P1 | DApp 翻译额度 | 翻译不同长度页面内容 | 按消耗 token 统计；前端不展示剩余额度 |
| P1 | 部分成功 | 让批量操作部分项目成功、部分失败 | 仅按实际完成项目扣减额度 |
| P1 | 月度重置 | 到达 Dashboard 配置的重置时间后重新进入功能 | 额度按月重置为配置值 |

## 3. 锁定与异常回退

| 优先级 | 场景 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- |
| P1 | 批量功能发起锁定 | 发起批量复制地址、批量发送或批量取消授权 | 先锁定一次额度，执行中不可重复占用同一次额度 |
| P1 | 正常完成 | 完成全部或部分操作 | 锁定额度按实际完成项目扣减，未完成部分释放 |
| P1 | 主动退出/失败 | 在执行中退出或让流程失败 | 锁定额度回退，不形成永久扣减 |
| P1 | 批量复制地址异常退出 | 非正常退出后等待 10 分钟 | 锁定额度自动回退 |
| P1 | 批量发送/取消授权异常退出 | 非正常退出后等待 30 分钟 | 锁定额度自动回退 |
| P1 | 跨客户端锁定状态 | 账号仅剩最后一次额度且该额度被客户端 A 锁定 | 客户端 B 展示额度解锁时间 |
