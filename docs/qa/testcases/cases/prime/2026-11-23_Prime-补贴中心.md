# Prime - Gas Account 补贴中心

> 需求文档：`docs/qa/requirements/Prime-补贴中心.md`  
> 规则文档：`docs/qa/rules/prime-rules.md` 第 `4.16` 节  
> 测试端：Desktop / Extension / iOS / Android / Web  
> 更新日期：2026-11-23  
> 需求：[OK-67058](https://onekeyhq.atlassian.net/browse/OK-67058)

## 前置条件

1. App 已解锁；至少准备 2 个 TRON 地址（软件钱包），其中含未激活地址（余额不足 0.1 TRX）和已激活地址。
2. 准备未登录、已登录且无记录、已登录且有补贴记录的 OneKey ID。
3. 准备可领取免费能量的日期窗口，以及无效兑换码；有有效兑换码时执行兑换码正向行。
4. 当前页面文案为中文，按中文验收。

## 测试数据

| 数据 | 取值 |
|------|------|
| 主入口 | 钱包「更多」→「补贴中心」 |
| 日领取重置 | GMT+8 00:00 |
| 能量有效期 | 到账后 10 分钟 |
| 未激活门槛 | 充值 ≥ 0.1 TRX |
| 概览记录条数 | 最多 6 条 |
| 记录窗口 | 近 90 天 |
